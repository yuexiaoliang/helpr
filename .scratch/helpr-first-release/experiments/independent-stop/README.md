# 独立停止与迟到结果实验

这是 [验证独立停止与迟到结果的处理](../../issues/02-independent-stop.md)的可重跑实验，用于确定后续执行器必须满足的控制约定。代码与受控网页仅用于取得运行证据，不是产品实现或最终架构。

## 运行

在本目录执行：

```sh
npm ci --ignore-scripts --no-audit --no-fund
npx playwright install chromium
npm run run
```

固定依赖为 Electron 44.7.0 和 Playwright 1.64.0。Electron 的依赖入口在二进制缺失时下载对应版本。需要能够显示窗口的桌面环境；本次在 macOS arm64、Node.js 24.18.0 上执行。

脚本启动只监听本机回环地址的测试网站，依次运行 Electron 双视图和普通 Chromium 双标签页。两个候选均通过外部 CDP 连接使用 Playwright；使用独立浏览器配置，不加载日常浏览器资料或业务账号。全程自动操作，无需真人输入，完成后关闭本次窗口和测试网站。

## 实验组成

- `control.mjs`：实验用 `ExecutionControl` Module。Interface 包含本次执行的凭据、动作派发、停止和在途调用结束确认；内部检查执行归属与代次，并传递 `AbortSignal`。每次派发只包住一个浏览器原语。
- `run.mjs`：两个候选各运行 11 个场景，核对页面快照、真实 HTTP 请求和控制事件。
- `lab.mjs`：记录事件，并控制网站提交及模拟模型响应的返回时机。
- `fixture.html`：实验页面，提供计数、等待可用的按钮、连续输入、提交和文件选择。
- `electron.cjs`：承载两个 `WebContentsView` 的实验窗口。

上传样本是在内存中生成的 64 KiB 文件。模型响应来自本机 HTTP 实验桩，没有调用真实模型服务。受控页面中的选择器和操作仅是测量工具，不是产品内置的业务流程。

## 结果

每次结果保存在 `artifacts/<时间>/`：

- `results.json`：版本、起止时间、逐项预期、观察结果、页面快照及停止后的派发检查。
- `events.jsonl`：按 `sequence` 排序的控制、网站及页面事件。`scope` 对应候选与场景，`task` 区分 A/B；页面事件另带实际发生时间 `eventAt`，不能把服务器收到事件的时间一概当作输入时间。
- `profiles/`：隔离的浏览器配置，忽略提交。

`artifacts/latest.txt` 是不进入 Git 的本机指针。报告引用的结果和事件记录保留在 Git 中。

**`passed` 表示该场景的预期得到验证。** `promise-race-negative` 和 `opaque-command-negative` 故意复现错误停止方式；它们通过意味着反例出现，不能计作停止成功。正常正对照与已接收提交的边界检查也不能混同为取消成功。完整解释见 [实验记录](REPORT.md)。

## 测量边界

覆盖待派发动作、等待中的点击、已开始的连续输入、排队重试、迟到外部回复、旧代次回复、网站已接收的提交和上传，以及不合作的浏览器内部工作。每项都检查 B 可以继续推进且两个页面仍可读取。

本实验没有验证真实模型取消、完整 AI 执行器、真人接管识别、上传传输中的取消或跨进程恢复。后续组合必须实际接入并验证，不能从本实验推导任意 SDK 或整段代理循环都已支持停止。
