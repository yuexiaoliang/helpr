# 恢复依据自动形成：有界实验计划

2026-10-12。对应[验证恢复核对依据的自动形成](../../issues/23-autonomous-recovery-evidence.md)。这是一次性技术实验，不是产品实现。

## 问题和边界

采用已验证的私有 Electron pipe → 能力转接 → Playwright 路径，以及先保存再派发的本机 SQLite 记录。复用分阶段流程实验中模型学得的操作和结果条件；**不读取旧恢复实验中人工编写的 recovery-contract.json**。本轮新增的保存动作、稳定地址识别、恢复结果入口和恢复条件必须来自实际网页观察及模型提议。程序只检查观察出处、唯一定位、任务／素材／执行归属和条件覆盖。

网页动作仅作用于既有独立验证后台 `http://home.ts-ali.internal:38080` 的本轮虚构新建记录。现有测试授权和本次“继续”用于完成该 AFK 事项；以下额度独立登记，不继承或重置任何旧实验额度。测试代理知道后台请求格式，只用于计数、阻断写入、扣留回执和独立核验，不能向候选提供记录编号或恢复地址。

## 固定额度

- 最多 4 个有效业务样本：学习样本 L、上传后中断 U、换输入后保存中断／发布丢回执 H、最终派发间隙 G。
- 包含失败在内最多 **6 次新建准备、6 次实际上传、3 次发布请求、1 次夹具外部修改**。多出的 2 次准备／上传和 1 次发布只供已定位故障后的有界重跑；任何结果不明的旧工作不以重跑替代核对。
- 最多 **24 次浏览器宿主启动**（学习、冷恢复与故障重跑均计数），最多 **4 次通用程序修订**。每次启动留存版本摘要及全部事件。
- 最多 **12 次真实模型请求、140,000 个累计 token**；请求前按 UTF-8 字节数加最大输出预留上界，未知用量按预留计入。格式纠错、失败、重试均计数；不自动重试。
- 首次浏览器启动后最多 90 分钟实验时间。冻结后保留集不允许修改候选或规则；如暴露故障，原样记录为失败，是否另做实验需形成新的具体方案。
- 只读核对最多 30 次任务恢复调用、80 次独立公开结果读取；不额外创建文章。程序和文档的静态检查不消耗业务额度。

## 顺序和判断

1. L：经既有模型流程准备材料。从真实控件观察选择保存动作，保存当前导航及已核对的上传地址／摘要。模型从保存后的当前地址提议稳定身份规则；只能选择已存在的地址组成部分。发布后，从实际重开编辑页观察中选择公开结果入口；结果条件沿用已有学习证据且必须覆盖所有输入。
2. 冻结：保存所有候选源码、依赖摘要、规则及提议出处的摘要。后续 U/H/G 使用新输入和新进程，不向候选填入任何文章编号、记录地址、网站定位或成功规则。
3. U：上传被核对并保存后终止进程，尚未完成草稿保存。恢复必须保留已上传事实；若无稳定目标身份则保持未知，不再次上传／新建。
4. H：与 L 同名但正文、文件字节不同。保存引发的导航一出现便保存；在“已准备”检查点之前终止进程。新进程核对全部草稿输入后仅续做剩余发布。代理在后台已接收发布并返回后扣留回执，终止进程。再开进程仅凭普通记录核对真实结果；另在核对成功、记完成之前终止，验证再次恢复不重发。
5. G：最终发布派发记录成功但调用浏览器前终止。即使网页仍是草稿，也不根据“尚未看到成功”重发，保留未知。
6. 使用明确标记的意图夹具检查停止、人工接管、待确认、未知输入暂停及显式继续。旧资格／旧提议不能重新取得控制。以已形成证据构造缺失覆盖、错误位置、跨执行身份、同名及素材版本反例；不得把夹具注入当真人确认。
7. 在 L 的本轮记录上由独立夹具修改正文一次，候选必须拒绝认领旧结果。独立核验以真实网页、后台请求计数和附件下载摘要为准，不能只读取候选的“完成”。

## 记录与限制

保留每次失败、原始提议、观察、进程终止点、人工干预和额度消耗；凭据、cookie、API key 不进入可提交证据。新增 HTTP 导航只放行任务中已登记的验证站点，文件登记来自固定素材版本；不开放全权 CDP。只读恢复由代理阻断网站背景写请求，已存在作用仍可能晚到，不能把进程退出解释为撤销。

该方案验证“已有运行时流程上形成并复用恢复依据”，不宣称任意网站、任意未知状态、完整新网站学习或全体浏览器生命周期已经通过。若自动形成失败，记录具体断点和需要的人工信息，不降低核对标准。
