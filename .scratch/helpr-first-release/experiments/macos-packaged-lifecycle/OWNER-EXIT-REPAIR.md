# 移除退出诊断报错后的打包核对

Status: passed-and-stopped

2026-10-13（Asia/Shanghai）。[原生现场](NATIVE-EXIT-DIAGNOSIS.md)已找到 build-8 的明确新错误：`will-quit` 诊断统计访问已经销毁的 `WebContentsView.webContents`，抛出 `TypeError`。用户截图指出具体行；同一进程的主线程采样停在 `NSAlert runModal`。用户确认点击过弹窗的“好”，所以随后进程消失不能算无人参与退出通过。这解释 build-8 的诊断弹窗，不倒推解释没有该统计行的 build-7 历史失败。

## 已准备的具体修正

[host.cjs](src/host.cjs)只删除 `will-quit` 中对网页对象的统计，保留退出事件记录；不屏蔽未捕获异常，也不增加强制结束来伪装正常退出。其它源文件与 build-8 一致。

[回归检查](verify-owner-lifecycle.mjs)已增加真实故障条件：网页关闭后 `webContents` 不再存在。旧候选复现与截图完全一致的报错，[修前失败](artifacts/owner-destroyed-view-before.json)；移除访问后九项均通过，[修后记录](artifacts/owner-destroyed-view-after.json)。实际退出仍以 OS 进程全部消失为判据，不以 `quit` 事件或源码检查代替。

[实际核对脚本](verify-owner-reopen-v3.mjs)沿用原两项未知工作，验证真实控制进程中断、无人工参与的全进程退出、冷启动后的未知／等待保留、正常退出保存顺序及网站不重做。若失败，在清理前采集宿主线程栈，防止再次丢失现场。
