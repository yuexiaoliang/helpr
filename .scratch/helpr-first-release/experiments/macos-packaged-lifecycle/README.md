# macOS 封装、更新与运行恢复实验

状态：本次有界实验已结束，限定结论已归档到[封装、更新与运行恢复](../../issues/25-macos-packaged-lifecycle.md#answer)。先读 [PROGRESS.md](PROGRESS.md) 和 [PLAN.md](PLAN.md)。本目录属于一次性技术验证，不是可交付产品。

最新[修后打包核对](OWNER-EXIT-REPAIR.md)已通过：build-9 在控制进程中断后约 186 毫秒内自动结束全部 12 个自有进程；重开保留原未知与等待，正常退出先保存再清理，网站没有重复效果。四项实际检查通过，当前无实验进程；[结果与范围](artifacts/owner-exit-repair-outcome.json)。构建 9 / 9、安装 7 / 7、启动 19 / 19、故障 16 / 17、HTTP 409 / 1,000，模型和远程业务写入均为 0。

修前失败仍保留：build-8 的[单独复验](OWNER-EXIT-REVALIDATION.md)记录实际进程残留；后续[原生诊断](NATIVE-EXIT-DIAGNOSIS.md)定位了退出统计访问已销毁网页对象的异常弹窗，用户点“好”后退出不计自动通过。旧源码准确复现此错误、修后九项检查通过；最终实际判据在 `verify-owner-reopen-v3.mjs`，不以源码回放或退出事件代替进程消失。诊断代码只保留在这一实验及冻结证据中，未进入产品源码。

当前事实和待完成项见 [PROGRESS.md](PROGRESS.md)。独立双页操作、关闭／重开和更新资格已有受控证据；真实升级到 0.0.2 后，经系统授权读回原密钥并核对任务。连接竞争修后对照、旧备份恢复及授权后同版重开分别通过。旧 Cookie 已过期，跨升级登录保留仍未证明，也不能宣称升级后无需人工参与。初次证书信任提议已撤回，始终没有修改系统信任。

构建产物、应用包、安装副本、浏览器资料及签名私钥均忽略提交；源码、来源、预算和脱敏运行证据保留。真人网页点击、中文输入及恢复保留通过；build-7 真实休眠消除了“已唤醒但仍锁屏时提前派发”的反例，但当轮意外退出仍失败。各构建的事实分别记录，不能拼成全部产品能力已验收。正式签名与更新来源、跨升级登录和系统授权，以及完整组合中的两项并行与生命周期仍须按后续验收安排验证。
