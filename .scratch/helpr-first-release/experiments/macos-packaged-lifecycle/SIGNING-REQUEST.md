## 已撤回的临时信任方案（保留原提议）

仅对本次新建的[实验公钥证书](lab-signing.cer)添加当前用户域的 `codeSign` 信任；不加入管理员信任域，不启用 SSL 信任，不关闭 Gatekeeper，不修改系统总开关。证书名 `helpr Lifecycle Lab 20261012`，SHA-1 指纹 `0A64F07EFA1ADDFF417EC018E622D71D539B8DE4`，有效期 7 天。

该信任适用于这张证书签署的代码，不是按某个应用文件名限制；本次私钥只用于实验 Bundle 和所属辅助程序，位于被忽略且仅本人可读的 `private/`。不向外分发、不用于其它应用。实验结束后撤销这张证书新增的用户信任。系统可能要求本人确认授权，届时只按实际弹窗说明。

获得用户明确同意后，拟执行的信任变更等价于（路径相对于本实验目录）：

```sh
security add-trusted-cert -r trustRoot -p codeSign -k private/lab-signing.keychain-db lab-signing.cer
```

随后重新验证身份，逐层签名并验证实际应用，核对新旧版 designated requirement；是否能升级及延续凭据由运行结果判断。静态签名、自用本机运行、系统安装评估和正式对外分发保持分开。

如果用户不希望添加这项临时信任，可由本人配置有效的 Developer ID Application 身份后继续。不会代为注册／购买会员或要求导出其私钥。正式发布源和公证仍在交付前独立落实。

此暂停来自[当前事项](../../issues/25-macos-packaged-lifecycle.md)已明确的约束：“不自动注册、购买、导出私钥、信任新根证书或降低系统安全设置。”不是系统自动审批拒绝，也不是已证明所有本机签名方案不可行。
