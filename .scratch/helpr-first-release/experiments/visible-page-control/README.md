# 页面归属与输入来源实验

这是 [验证真实网页的页面归属、并行与输入来源](../../issues/01-visible-page-control.md)的可重跑实验。代码仅用于取得技术选择所需的事实，不是 helpr 产品实现或最终架构。

## 运行

在本目录执行 `npm ci`，然后运行 `npm run run`。固定依赖为 Electron 44.7.0 和 Playwright 1.64.0；首次运行可能下载浏览器。普通 Chromium 需要 Playwright 对应的 Chromium 安装，可用 `npx playwright install chromium` 准备。

运行时建立监听于本机回环地址的测试网站，启动隔离的 Electron 与 Chromium 窗口，不加载日常浏览器配置或真实业务账号。两种候选各有两个相同 URL 的页面。

每次结果保存在 `artifacts/<时间>/`，`artifacts/latest.txt` 指向最近一次。`results.json` 是自动实验逐项结果；`events.jsonl` 是页面、扩展及测试服务器记录；`electron-native.jsonl` 是 Electron 宿主输入记录；`live.json` 保存启动时的实验进程与连接信息，是否仍在运行以实际进程状态为准。浏览器配置位于该次运行的 `profiles/`。浏览器配置、依赖目录、`live.json` 及 `latest*.txt` 本机指针不进入 Git；报告引用的实验结果、事件记录与截图保留为证据。

自动部分结束时终端输出 `READY_FOR_HUMAN`，窗口继续运行。完成真人对照后执行 `npm run summarize` 汇总现有证据；用 Ctrl+C 结束实验进程。

只需要重开 Electron 真人对照时，运行 `npm run manual`。它先自动检查完成入口能否经受刷新、导航和滚动，再显示两个空白输入的测试页面。输出保存在 `artifacts/manual-<时间>/`，`artifacts/latest-manual.txt` 指向最近一次真人运行；可用 `node summarize.mjs <输出目录>` 汇总。该入口不重跑双候选自动实验，关闭窗口也会结束其记录进程。

## 测量范围

- 同 URL 页面的 CDP target、WebContents 与扩展 tabId 对应关系。
- 两页点击触发的操作时间是否重叠、计数是否分别增长。服务器以短暂延迟模拟处理，仅用来测量重叠，不代表真实后台事务。
- 隐藏视图、后台标签、遮挡及最小化的操作表现；各运行条件分别保存，失败不被隐藏。
- 导航、跨 origin 导航和弹窗后页面身份及所属关系。
- 外部 CDP 连接与 Electron 内同一视图是否读写同一内容。
- 点击、字符键、直接插入中文、填充、脚本点击、脚本派发和 Electron sendInputEvent 的 DOM/宿主事件差异。
- 浮窗目标与业务网页输入是否相互影响。普通 Chromium 浮窗会进入网页 DOM，Electron 浮窗是独立视图；本实验不把布局差异当作最终选型。

输入样本中的 stage 是实验脚本标注的已知操作来源，用于对照，**不是产品可使用的来源判定字段**。自动样本的 `isTrusted` 及宿主钩子是否触发必须据实记录，不能预设能区分真人。

## 真人对照

真实输入必须由用户在实验窗口完成，agent 的 CDP、系统级输入模拟或脚本输入均不能代替。需要验证的候选至少完成一页的以下操作；两个页面可分别用不同短语确认归属。2026-10-10 本轮收敛为 Electron 的真人对照，Chromium 仅保留已完成的自动证据，其真人输入标为未验证；后续需要比较这一能力时再补样本，不要求用户现在重复操作两套窗口。

1. 仅移动鼠标、查看和切换标签页。
2. 点击“计数加一”。
3. 使用中文输入法在指定输入框键入“手动接管测试”。
4. 选中并复制页面样本“网页输入验证 2026”，粘贴到指定框。
5. 滚动页面并在浮窗输入“对话测试”，核对没有修改网页中的输入框。
6. 点击“本页操作完成”，在任务对话中说明已完成哪个候选，以及是否有异常。

只记录实验页面与实验应用的事件。请使用样本内容。人工完成标记只表明页面收到该操作，仍需与用户实际参与核对；自动化也能点击同一按钮。

“本页操作完成”位于页面上方并随滚动保留可见，刷新和同 origin 导航后仍保留真人模式。完成后也可直接在任务对话反馈，不需要为了按钮重复输入。此次真人对照无需使用“打开测试弹窗”或“进入下一页”，这两项供自动实验检查页面归属。

## 结果边界

本实验不调用模型、不发布真实内容，也不验证登录持久化、流程重放、独立停止或崩溃恢复。这些由地图中对应事项取得证据。DOM/宿主事件采集成功不等于接管识别已经可靠；仍需解释差异、反例及未覆盖输入。
