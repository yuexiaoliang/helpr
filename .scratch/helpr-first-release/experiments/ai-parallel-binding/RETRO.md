# 真实 AI 双页实验复盘

2026-10-11，America/New_York。复盘范围是本会话中完成的双页实验及其补测。主要失误由我操作实验时造成：根据过时观察中断仍在推进的运行，随后重复执行，耗尽已固定的调用预算，又单独开补测增加调用。原始记录和失败记录均保留；18 项场景证据成立，不代表实验过程遵守了原预算。

以下按严重程度排序。前三项是仍待实现的改进，第四项已在本次复盘中落地。

1. **P1：预算绑定证据目录，缺少覆盖全部尝试的总账。**

   原先固定 96 次调用，原目录用完 96 次后，[补测计划](artifacts/chromium-missing-cases/PLAN.json)另计 17 次，合计 113 次、103,489 个已返回 tokens，另有 3 次取消请求用量未知。预算偏差已在[报告](REPORT.md)披露，但另开目录没有遵守原先“失败和修订不重置预算”的承诺。

   [model.mjs](model.mjs)为缺少记录的目录建立新预算，而且把记录读取、JSON 解析等所有异常都当成首次运行；用量预留只在内存中，请求结束后才保存调用记录。硬中断后再次运行可能遗漏已发出的请求。`revisions` 上限也只有字段，尚无执行检查。已保存的修订字段为空；仅凭这一点无法确定丢失的原因。

   改进：以一次实验问题的固定标识管理总账，所有 attempt 和补测引用它；请求发出前持久化额度预留，未知用量保留估算；采用单写入者锁和原子替换，损坏记录直接报错。额度耗尽时记录尚未取得的证据并结束；追加预算作为明确变更记录，不能自动靠新目录获得。修订次数也由同一账本检查。

   验收：用本机假客户端验证换目录、进程中断、并发启动和账本损坏均不能多发一次请求；取消而无 usage 的请求仍占用预留；第 97 次调用及超限修订在请求发出前被拒绝。

2. **P1：中断判断没有使用最新状态，功能结果又与截图共用完成点。**

   [第一次中断记录及更正](artifacts/2026-10-11T03-38-56-107Z/attempts/01/interruption.json)说明截图已经在 30 秒后超时，脚本继续保存了 13 项结果。我仍按较早的截图等待判断卡住，并进行了全量重跑。已有 `HOST_FILTER`、`CASE_FILTER` 可以收窄范围，当时没有使用。信息已在日志中，失误不应归因于模型或 Chromium。

   改进：提供只读 `status`，一次展示当前 attempt、场景、阶段、最近进展、在途请求和剩余额度；中断前重新读取状态。功能断言完成后立即持久化，截图单独记录，补截图仅补采集。当前程序已将截图超时缩短并记录结果，但仍在截图与清理之后才保存整项结果，`revealForCapture` 失败也仍会进入整项失败分支。

   验收：故意拖延或令截图失败，状态应显示证据采集阶段，已有功能结果可读；中断并继续后不会为已完成场景再次调用模型。无新日志只能表示缺少进展信息，不能单凭它宣布死锁。

3. **P2：续跑兼容性检查覆盖不全，可能接受已经过时的通过结果。**

   [run.mjs](run.mjs)只比较 `worker.mjs`、`model.mjs`、`lab.mjs`、`electron.cjs` 四个文件；`run.mjs` 中的场景断言、`host.mjs` 的宿主连接、扩展、共享客户端与控制模块、依赖锁文件和模型配置均不在判断内。它们发生实质变化时，旧结果仍可能被自动跳过。这是代码检查发现的风险，没有证据证明本轮结果因此失效；本轮使用保留的源码快照复查。

   改进：将场景定义、执行依赖和纯证据采集分开，保存前两者的完整兼容性指纹与不含密钥的配置标识；只改截图采集可复用功能结果，改断言、宿主行为或执行配置则重新标记相关结果。

   验收：离线夹具分别修改断言、宿主、共享模块、依赖和模型配置，计划必须显示受影响场景待验证；仅修改截图输出位置时仍复用功能结果。计划读取出错时显示错误，不能默认当成没有历史结果。

4. **P2：已有检查没有统一入口，也没有自动运行的仓库防线——本次已接通。**

   检查前，客户端与重放实验各有 `npm test`，双页实验已有 `verify.mjs`；根目录无检查命令或 CI，`.git/hooks` 只有示例文件，`core.hooksPath` 未配置。这里应复用检查，而非把相同要求写进常驻提示。

   已新增根目录 [package.json](../../../../package.json)、[检查脚本](../../../../scripts/check.mjs)及 [CI workflow](../../../../.github/workflows/check.yml)。`npm run check` 检查当前源码语法、客户端夹具与已保存证据；`npm run test:browser` 运行已有重放回归测试，CI 同时运行二者。浏览器依赖按现有锁文件安装，并跳过真实实验的 `prepare` 生命周期脚本。

   `verify.mjs --check` 保留证据索引原样；`run.mjs --plan` 延迟加载宿主依赖，使只读检查可以在没有 Electron、Playwright 和模型凭据的环境中运行。本次未启动真实模型请求，未修改历史证据或执行协议，也未新增 AGENTS.md 常驻规则。

本地验证通过：64 个源码文件语法检查、6 项客户端测试、4 项浏览器重放测试、18 项保存场景的证据复查。在没有浏览器依赖的临时副本中，443 个文件在 `--check` 前后保持相同；故意篡改页面归属后复查拒绝通过。CI 配置已保存，远端运行仍需提交推送后验证。这些检查保护现有回归与证据，尚不覆盖前三项运行控制缺口。

下一次真实模型实验前，优先用离线夹具完成预算总账和状态／续跑改进。根目录 AGENTS.md 仅 27 行，现有导航已足够；本轮没有发现需要增加全局规则或额外信息权限的证据。
