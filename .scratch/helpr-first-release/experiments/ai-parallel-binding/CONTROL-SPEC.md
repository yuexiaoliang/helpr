# 实验运行防线

来源：[本轮复盘](RETRO.md)前三项。审查基点为 `ca89923`。本次改动服务于实验工具，使用本机夹具验证，不重新取得真实模型或浏览器并行能力的证据。

## 行为要求

1. 同一个实验问题使用固定账本，输出目录和 attempt 不决定预算。请求发出前原子保存调用与 token 预留；重启后，未取得 usage 的请求仍占用预留。只有记录不存在才允许按登记资料初始化，损坏记录直接报错。同一账本仅允许一个活跃写入进程；确认旧进程退出后可继续，无法确定时保留现场并报错。
2. 总账限制调用、tokens、截止时间和程序修订。初始化版本不算修订，之后每次版本改变计一次；相同版本继续不增加修订。达到上限时在请求发出前拒绝，并保留未执行项。历史实验按原上限和全部 113 次实际调用登记，不能因工具升级获得新额度。
3. 只读状态展示当前 attempt、场景、执行／采集／清理阶段、最近进展、在途请求、未知用量与剩余额度。状态包含读取时间和进程存活情况；日志安静不等于进程卡死。
4. 功能结果在断言完成后立即持久化，截图与清理另记结果。截图显示、截图保存或清理失败不能改写已经通过的功能结果。再次采集使用留存页面，不运行模型或重放网页动作；原页面不存在时报告无法补采。进程退出后续跑跳过已有兼容功能结果，并保留缺失的截图说明。
5. 续跑指纹覆盖场景断言、驱动、宿主、扩展、共享执行控制与模型客户端、依赖锁文件和不含凭据的模型配置标识。单独的截图采集实现与输出位置不使功能结果失效。变更任何功能依赖后，计划明确显示相关场景待验证。历史证据缺少完整指纹时仅供查阅，不自动视为当前实现已通过。
6. 计划和状态读取不加载浏览器依赖、不读取模型凭据、不改写记录。格式损坏或必需记录缺失时给出错误，不默认为空历史。

## 验证入口

用户已在本会话确认三个公开入口：模型请求；实验运行与只读状态；只读续跑计划。外部模型使用回环 HTTP 夹具，浏览器动作与截图使用受控系统适配器；真实文件写入和跨进程退出用于验证持久化与锁。每项从失败测试开始，逐项完成。

验收包含：第 97 次调用被拒绝；输出目录变化不重置额度；取消无 usage、并发启动、进程中断、账本损坏与修订超限；截图等待和失败期间可读取功能结果；重启不重复调用；逐类依赖变更使计划失效；截图位置变化保持复用；只读入口的文件内容保持原样。

历史实测继续按保存的源码快照复查，不将当前工具的新能力写成历史运行时已经存在的能力。新的回归测试接入现有 `npm run check`；已有浏览器回归保持在 `npm run test:browser`。
