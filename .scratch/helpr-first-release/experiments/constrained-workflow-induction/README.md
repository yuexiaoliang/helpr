# 受限提议归纳实验

一次性决策实验，未接入产品。测试网站只存在于夹具与运行时记录；通用程序不内置网站字段、栏目、动作路径或发布成功文字。

本轮已结束，**完整路径未通过**。实际结果与限制见 [实验报告](REPORT.md)。现存 `calibrate` / `evaluate` 完整候选代码未执行；没有可供使用的完整候选。

## 预先固定的预算

- 同一 `artifacts/run` 累计最多 80 次模型请求、400,000 个服务端返回的 token、70 分钟。超时请求的未知 token 单独记录。
- 归纳最多 50 次 / 250,000 token，校准最多 16 次 / 80,000 token，保留集最多 14 次 / 70,000 token。阶段额度不挪用，失败重启不清零。
- 每个提议最多一次格式修订；总计最多 6 次模型格式修订，最多 3 次程序协议修订。根据新观察作出的动作决策均计入总请求额度。浏览器无进展连续 3 次即停止；提交结果不明确时不重复提交。
- 冻结候选后才生成保留集：新文字、新素材、标题与网站常量碰撞、相近委托、控件变化。

## 固定职责

模型：从原始委托摘取输入与约束；从当前真实观察的编号控件中选择动作、输入来源、作用于控件名称的输入绑定；必要时选择字段或附件的观察位置；在公开页面选择每个输入的结果观察位置。

程序：校验每一阶段的封闭 schema；控件编号只在当前观察有效；仅生成已经唯一匹配的定位；保持输入、素材和授权摘要不可变；固定 fill 的相等语义、check 的布尔语义、附件的原始字节哈希；条件不允许模型填写期望值；按真实动作记录组装流程。点击的阶段条件取下一步实际可用控件，不能当成业务成功证据。

所有非安全 HTTP 请求在网络处检查条件，只有严格匹配授权素材的 multipart 上传例外；条件尚未完整时的自动保存也可能被阻止。全部输入已映射后，每次动作都重核已形成的条件，不依赖模型的 effect 标签。此实验不声称识别任意网站副作用：有副作用的 GET、其它传输通道、后台异步行为和服务器内部语义仍是限制。

运行：在本目录执行 `node run.mjs learn`、`node run.mjs calibrate`、`node run.mjs evaluate`。共用上面的累计预算。浏览器原语与模型客户端使用此前已安装并验证的实验依赖。

`node diagnose.mjs` 沿用冻结的第三版协议，复现局部前缀、观察上传请求形态并测试错误的发布效果标签；不修改执行规则。`node summarize.mjs` 从原始记录重建证据索引，不调用模型或浏览器。原运行已达到协议修订上限，不应重置其预算继续执行。
