# 浏览器控制连接与宿主隔离：冻结前方案

用途：为[验证浏览器控制连接与宿主隔离](../../issues/24-private-browser-control.md)取得受控运行证据；不是产品实现或安全认证。

## 候选与 Interface

- Electron 44.7.0，由长期控制进程用 `--remote-debugging-pipe` 启动；控制进程独占 fd 3/4。不开启调试 HTTP/WS、Node inspector 或任意本机控制监听端口。
- Playwright 1.64.0 的本地发布类型与实现已包含 `connectOverCDP(ConnectOverCDPTransport)`，可直接适配受管进程通信；不需要另开 WebSocket 转接。这修正了前次仅依据网页文档推断只支持 HTTP/WS 的限制。调用公开重载，不调用 `_electron.launch` 或 Playwright 私有启动器。
- 控制 Module 的 Interface 是受管子进程通道、当前执行资格、允许的协议能力及已登记页面。每条消息重新检查通道身份、随机资格、期限、撤销状态；凭据不进入网页、环境变量、启动参数、普通日志或证据文件。
- 浏览器级协议采用显式允许列表；展示、附着及事件按宿主登记的目标归属转接。子 frame 的协议 session 继承实际父 session 的归属。旧 session、另一通道的 session、未知 target 及未覆盖的能力默认拒绝；不能用一个全权原始 CDP 入口作为旁路。
- A/B 为独立 WebContentsView。允许列表不承诺消除网站共享登录或服务端记录的相互影响；这些仍由已有共享条件约定协调。宿主对话使用独立来源与会话；远程网页没有宿主 preload 能力。显式 sandbox、contextIsolation、webSecurity，关闭 Node 集成；导航、popup、权限和下载由宿主管理。

## 固定预算

最多 **8 次 Electron 启动**，每次最多 **100 项场景、20,000 条转接协议命令、1,000 次本机 HTTP 请求、240 秒**；全部证据不超过 **400 MiB**。每次启动前保存候选、测试、页面及本方案的源码快照和 SHA-256；失败和未完成运行一并保留。耗尽即停止并记录，增加预算须另行说明。

模型调用、远程上传和发布均为 **0**。只访问本轮创建的回环 HTTP 页面与虚构数据；不使用真实登录、模型凭据、不扫描无关应用或端口、不执行外部协议或下载文件。监听面只检查本轮拥有的进程及其子进程。网页 HTTP 仅是实验夹具的例外，不作为交付网站的传输要求。

## 判定与反例

1. 实际 Playwright 两页读、填、点及重叠请求；当前资格可用。
2. 独立客户端的无资格、伪造、过期、撤销、跨通道资格，以及重连、旧 session、A 指向 B 的 target/frame/session 均拒绝；B 内容不受攻击改变。
3. 宿主登记的正常导航、popup 和跨站 iframe 可操作且保留任务归属；未登记目标不可自动接管。浏览器级关闭、创建 context、嵌套协议通道、文件访问等未覆盖能力拒绝。
4. 停止 A 后，新动作被拒绝，A 已接受的请求可以晚完成；B 真正继续操作，宿主存活。控制进程被终止后，私有 pipe 关闭，Electron 与工作者结束，不留失管派发。
5. 网页及子 frame 尝试宿主 API、文件导航／读取、宿主来源、外部协议、popup、下载与权限；核对受阻和正常网站能力的对照。不得以测试夹具的网络围栏替代产品宿主隔离结论。
6. 保存完整启动参数、进程列表／监听记录、版本、协议方法覆盖、失败响应及独立网站请求账本。凭据仅在内存中保留以核对证据不泄漏；校验器只读，不能补写成功结论。

## 已知不覆盖

没有 Chromium/Electron 漏洞审计、操作系统受侵后的隔离、任意 CDP 方法的安全证明、真实网站完整流程／上传发布、真人接管、签名打包、休眠与升级兼容。拒绝未覆盖能力可能需要后续增加经核对的 Adapter；不能静默放开全权协议。若该限制导致原定流程无法成立，在对应后续事项中继续验证或重新讨论路线。
