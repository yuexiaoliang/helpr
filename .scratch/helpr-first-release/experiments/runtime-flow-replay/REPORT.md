## 流程保存与修复

[原始流程 v1](artifacts/2026-10-10T10-30-00-complete/workflow-v1.json) 保存通用动作、目标 frame 和定位方式、操作意图及参数引用。标题、正文和文件路径均由当前输入绑定，步骤中没有固定发布文章 ID 或附件 URL。等待条件通过目标可见／附着及 Playwright 动作就绪检查实现；同名写入目标存在歧义时停止。

学习时写出的文件与冷重放加载的文件 SHA-256 相同：

```text
v1 5c5d9e16a3327ed37fb5a84d9bb18fea1cd929fcb145bec0752a872866d40313
v2 6aaf61601489e42fd852d7d4c7f277e4a28af75a2e367ecb158d9f0cdda9ba00
```

受控变化只修改当前测试页标题控件的可访问名称和占位属性：从 `Add title` 改为 `文章标题（新版）`，服务器、网站代码与正文没有改动。旧定位超时后，模型根据新快照选择真实名称，仍然填写 `{{title}}`。新旧流程的动作差异只有这一处名称。

实际文章与附件核对成功后，才写出 [流程 v2](artifacts/2026-10-10T10-30-00-complete/workflow-v2.json)。它保留父版本摘要和本次验证结果；原版不覆盖。随后另一个进程在同样的控件变化下加载 v2，使用第四份素材完成发布，模型调用为 0。这证明了本次受控变更的修复更新，不代表任意网页变化均可自动修复，也不证明并发修复、原子提交或回滚协议已经具备。

## 失败样本与修正

全部失败记录保留，没有把最终成功写成首次成功：

证据中的临时网页 nonce 已脱敏；模型 Key、网站口令和浏览器登录 Cookie 不进入报告或 Git。各阶段源码摘要记录运行当时版本，后续日志脱敏不改变操作与结果事实。

1. [第一轮](artifacts/2026-10-10T10-19-27-238Z/learn/results.json) 实际发布出文章，但实验核对失败。富文本输入后可访问名称改变，使用旧名称重新查询导致成功输入未被记为成功；前台又在“更多文章”中重复标题。修正为针对刚才输入的同一元素核对，以及核对公开文章的一级标题。未把这轮不完整记录提升为可复用流程。
2. [第二轮](artifacts/2026-10-10T10-22-51-248Z/learn/results.json) 模型重复点击尚未展开的菜单链接，达到 8 次失败上限后结束，没有发布。补充控件是否在视口内的观察信息、明确失败反馈，下一轮由模型选择先展开菜单。两轮提示和观察同时变化，不能把改善单独归因于某一句提示。
3. [第三轮的首次冷重放](artifacts/2026-10-10T10-25-45-629Z/replay/results.json) 已完成发布，但结果链接同时出现在页面和提示条中，唯一性检查失败。只读结果读取改为检查所有匹配链接：URL 完全一致才接受；写动作仍要求唯一。学习记录没有手工改写。随后同一 v1 流程在新进程通过。源码摘要保存在阶段记录中，不能把这组证据说成四个阶段使用完全相同的实验代码。

对第三项的 [独立事后核对](artifacts/2026-10-10T10-25-45-629Z/replay/audit-existing-result.json) 证明 [文章 16](http://home.ts-ali.internal:38080/?p=16) 和附件已正确存在。**执行器报错不等于网站没有发布。** 这里没有尝试重跑同一执行；后续实验使用新的标题和素材标识。提交中断与重复发布防护仍由后续事项验证。

成功学习本身也经历了三个可恢复失败：编辑器尚未就绪时定位错误、同名 Publish 按钮产生歧义、发布后等待已消失的旧按钮名称。最终流程只保存成功步骤，但还包含重复且较弱的可见性等待。当前证据支持最小路径，不能推导为复杂异步上传、任意加载时序下的充分等待协议。

全部实测共调用模型 49 次，提供方记录的总用量为 338830 tokens，包含失败探索；其中最终通过链为探索 20 次、修复 1 次。没有执行最终产品的提示优化或模型横向评测。

## 本地检查与剩余边界

`npm test` 的 4 项真实浏览器回归检查通过：输入后控件改名、相同结果双提示、不同结果链接冲突、同名写目标拒绝点击。实验文件语法及 Git 差异检查通过。

未验证：自由委托的流程匹配、素材内容解析与预览确认版本、第二个后台、Electron 中的 AI 执行器、Stagehand 适配、并行、人工接管、停止、中断执行恢复和定时任务。结果断言目前属于明确的测试用例，尚未证明能由运行时学习自动形成完整的通用结果核对规则。此实验只保存新执行可重放的做法，不保存浏览器内部运行栈。
