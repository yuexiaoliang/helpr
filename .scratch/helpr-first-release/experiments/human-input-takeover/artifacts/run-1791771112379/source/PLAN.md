# 人工接管输入实验计划

2026-10-11 领取[验证人工接管的输入识别与让出操作](../../issues/12-human-input-takeover.md)。只取得支持选型的机制证据，不构建产品。

先验证 macOS / Electron 的应用内原生事件观察，与已允许的 CDP / Playwright 自动输入是否分离。应用内鼠标命中与键盘实际响应视图决定任务归属；查看、移动、滚动、宿主标签切换及独立对话浮窗不应让网页任务接管。原生事件本身不证明物理真人，系统自动化等未经允许的输入通道不能计入保证。

复用 `independent-stop/control.mjs` 的逐原语凭据、失效与取消。来源观察进入同一 Electron 主进程的停止入口，避免先异步传给外部进程再停止。保留派发、取消、实际页面结果和迟到工作拒绝的分别证据。已派发动作不保证撤销，继续前等待旧调用结束并读取当前页面。

仅在本机回环地址的虚构页面工作，两个任务 A/B。无模型调用，无业务后台写入，不监控其它应用，不采集非实验窗口的输入。自动反例与模拟原生事件均明确标为测试注入；真人点击、中文输入法、粘贴及显示反馈只能由用户提供。

准备阶段最多两种来源机制、三次机制修订、六次自动组合执行、60 分钟；先保存每次失败再修订。源码、编译条件、自动和真人记录分别保存。达到限制则记录取得的事实与尚缺证据，不重置计数。真人操作等待不计入准备窗口，不自动超时认定通过。

先完成可独立进行的自动检查和清晰的实验窗口，再请求用户按窗口指引操作。至少分别取得点击、中文输入和粘贴首次触发接管的样本；包括 A 让出时 B 继续、浮窗输入不接管、迟到回调不得恢复旧执行、明确“继续”后核对当前状态并恢复。

参考：[Apple 应用内事件观察](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/EventOverview/MonitoringEvents/MonitoringEvents.html)说明该观察位于应用事件分发且处理在主线程；[Electron 原生窗口句柄](https://www.electronjs.org/docs/latest/api/browser-window#wingetnativewindowhandle)在 macOS 为 `NSView*`。文档只支持候选机制，具体输入是否经过该通道、归属与时序仍须本轮实测。
