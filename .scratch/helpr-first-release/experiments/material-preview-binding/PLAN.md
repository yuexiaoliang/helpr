# 素材、预览与发布版本实验计划

一次性 AFK 探路实验，回答“验证素材、内容预览与发布版本的关联”，不实现产品。

## 范围与预算

- 使用两份明确虚构的 Excel 版本、已有 DeepSeek 配置及独立 WordPress 测试后台。仅创建带本轮标记的测试文章和附件，不修改已有记录或网站设置。
- 最多 6 次真实模型请求、40,000 token；单次输出最多 1,800 token。模型只组织内容，不重新学习网页操作。失败和中断请求继续计入同一账本。
- 最多 4 次网页准备、4 次上传、4 次发布提交；预期 3 次成功发布。网页重放不调用模型；派发前持久记录计数，结果不明时不重发。
- 首次正式运行起 50 分钟；预算耗尽保留事实与失败，不换目录清零。只读核对与整理资料不耗发布额度。
- 所有确认、编辑和自动发布约定均标注 `experiment-injected`，仅检验版本控制，不冒充真人内容认可。产品默认预览确认、各任务独立确认及明确约定后的自动发布保持不变。

## 实验顺序

1. 保存素材字节快照和摘要，独立解析工作表、坐标、类型、公式及缓存值。用小型人工已知数据检查解析；零值与空白不同。保留解析器与生成输入版本。
2. 真实模型分别为 A、B 组织内容，建议中的事实引用具体单元格，计算保留输入引用。正文渲染完成后连同标题、附件、目标和处理要求形成不可变版本。
3. 同路径替换 Excel。证明旧快照不变，新字节不能混进旧预览。实验中明确把 A 改选为新版并重新生成；B 保持原已选快照。素材路径变化本身不被解释为用户要求改选，也不预设所有任务必须追随最新文件。
4. A 的新版内容再经一次明确标记的文字编辑。旧预览回复、跨任务回复、重复回复均应拒绝。A 的有效确认不能批准 B；B 可在自己的确认范围内发布原快照。
5. 模拟一个明确约定的自动发布任务 C，使用新素材。约定版本、素材范围、目标与处理要求匹配才准入；改变目标、要求、撤销约定或任务归属时旧授权无效。
6. 冻结执行参数，跨进程重新读取并校验内容、授权、素材和流程摘要。通过既有真实模型学得的流程在网页新建发布，逐次核对页面中的正文、目标和上传附件字节，再从未登录页面下载并逐字节比对。
7. 独立用原始 Excel 单元格和公开文章实际文字核对事实、数字、预览正文、目标及附件，不只验证模型 JSON 或动作返回。保留失败与所有来源链。

## 对照与边界

本轮用候选版本记录约定验证错误版本是否被拒绝。变更正文参数、附件字节、目标、执行身份，以及停止后仍到达的旧确认，都在网页写入前核对；执行中实际网站副作用归属仍沿用已有实验的局限，由“验证网页动作、上传数据与写请求的关联边界”独立处理。

Excel 列名、模型提示、预期事实和 WordPress 页面断言只属于实验用例。通用版本校验不识别“数量”列或“Publish”按钮。模型的来源引用不等于语义正确；本轮仅对虚构样本逐项核对，不宣称任意表格和文章都能自动保证事实。
