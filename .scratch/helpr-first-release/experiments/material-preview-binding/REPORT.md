# 素材、预览与发布版本实测

2026-10-12（America/New_York）。一次性技术探路实验，不是 helpr 功能实现或真人内容验收。决策与最小记录要求见[验证素材、内容预览与发布版本的关联](../../issues/13-material-preview-binding.md#answer)。

## 结果

使用两版虚构 Excel、4 次真实 `deepseek-flash` 内容调用，以及此前真实模型学得的 17 步网页流程，在独立 WordPress 后台完成三次发布。每次发布运行在不同进程与新页面，网页重放模型调用均为 0。原始记录保存在 [本轮目录](artifacts/current/)，调用和副作用均未超出[预先固定预算](PLAN.md)。

- [36 项独立产出检查](artifacts/current/independent-verification.json)通过。直接从原始 Excel 取编号、数量、单位和独立合计，与未登录页面实际文字比对；同时检查标题、备注、分类及完整下载字节。核对程序不调用内容生成或版本校验函数。
- [三篇文章的精确正文核对](artifacts/current/exact-public-verification.json)通过。根据实际页面确认的正文容器，核对只有预期的正文段落与附件块；正文逐字相等，两个附件入口指向本次实际结果。此检查补充全文包含判断，排除了仅在页面其它位置碰巧出现相同内容的情况。
- [记录链审计](artifacts/current/audit.json)通过：64 个审计条件，13 个实验源码摘要，4 份模型输入／输出与解析来源，3 份冻结执行记录、参与回复或约定、提交前观察和实际结果。此计数是证据完整性检查，不能解释成 64 个额外产品场景。

两次发布前分别读取实际编辑页面的标题、完整正文、分类及已上传文件，并读取附件字节进行比对。上传使用已经核对的同一份 Buffer，避免再次按可变原路径读取。公开页面从新的未登录浏览器上下文访问，Download 实际下载文件。

网站给 C 的附件追加了 `-1` 文件名后缀，实际下载摘要仍是 v2。这一事实支持记录实际 URL 与字节版本，不能把原文件名等同于网站结果身份。

## 用量与环境

- 真实模型调用 4 / 6 次，提供方返回合计 6,018 / 40,000 token。四次 HTTP 200，无模型修复或失败重试；用途均为内容组织。
- 网页准备、上传及最终发布提交各 3 / 4 次。正式模型与发布运行从 06:12:16 至 06:18:06 UTC，处于 50 分钟预算内。后续均为只读核对与整理。
- Node `v24.18.0`；Chromium `156.0.8078.4`；openpyxl `3.1.5`。生成 Excel 使用本机 bundled Artifact Tool。登录态复用既有专用测试作者账号，未读取或记录口令。
- A、B、C 的公开截图均成功保存，证据优先落盘，截图失败不会触发重发。本次没有运行中的失败样本需要隐去；预期拒绝的输入与原因全部保留。

## 可用范围

本实验验证的是所选素材、已生成内容、确认或约定、执行参数及可观察产出之间的版本关系。A/B 的预览和确认共存，但网页发布按顺序进行，不能算双网页并行的组合验证。没有模拟机器断电、多恢复者竞争或持久化事务；执行记录能被新进程读取，不等于完整恢复协议已经实现。

正文由模型组织来源占位和引用，再由实验程序渲染具体值。数字与直接引用可以核对；引用正确不自动证明自由文字的语义、选取范围或业务解释正确。四份建议由 agent 逐项阅读，且三篇实际文章通过已知用例断言。尚未证明任意 Excel、复杂公式、单位换算或任意文章的自动事实审核。自动发布正例验证已注入约定的匹配及版本失效处理，不证明自然语言约定识别或所有内容质量判断已经实现。

网站步骤复用此前学习结果，未重新探索。为避免沿用早期仅等待控件可见的弱判断，本轮在发布按钮前增加了独立的测试就绪断言；没有把这些手写断言说成新学得的通用能力。Excel 列名、标题格式、预期数字与当前主题选择器都只在夹具或断言中。

该实验没有建立每一条后台写请求与网页动作的完整因果关系，也没有证明请求传输中的每个字节均获授权。实际结果相等不能抹去[网页动作、上传数据与写请求的关联边界](../../issues/18-action-request-association.md)中的未知。存储、确认消费、派发和结果记录的原子性由[执行记录、流程更新与定时恢复约定](../../issues/10-durable-execution-contract.md)继续确定。
