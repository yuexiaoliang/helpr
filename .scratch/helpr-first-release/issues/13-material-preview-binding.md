## Question

前提：[模型 API 接入条件](03-model-api-access.md)、[参数化流程冷重放证据](05-runtime-flow-replay.md)和[用户参与状态模型](09-participation-state-model.md)。

当任务从“原样上传附件”变成“读取 Excel、提出内容建议、确认后发布”时，哪些通用的数据与版本关系能保证最终发布对应被确认的内容和原始事实，而不是后来变化的素材或旧的确认回复？

用虚构 Excel 和真实模型取得最小运行证据：保留来源文件版本与单元格事实，产生带来源关联的内容建议，将确定的内容版本绑定到流程参数，然后通过已有测试后台核对实际产出。覆盖素材在预览后发生变化、内容修改后旧确认迟到、两个任务使用同一素材但各自预览的情况。

沿用默认预览确认及明确自动发布约定，不重新询问已经确定的产品规则。实验可以注入明确标记的确认消息以检验版本控制，不冒充真人内容认可或完整 UI 验收；用户参与的交互仍由前置状态原型核对。

目标是取得来源、解析结果、内容版本、确认范围、执行参数和发布结果之间的最小记录要求，供持久化协议与实现规格使用。不得把某个 Excel 列名、某个平台文章格式或一次生成提示固化为产品业务规则。不能仅以模型返回了 JSON 就宣称事实保持或预览一致性通过。

## Answer

2026-10-12：完成两版虚构 Excel、4 次真实模型内容生成、3 次独立进程网页发布及实际下载核对。23 项版本检查、36 项独立产出检查和三篇精确正文检查通过；记录审计核对了 13 个源码摘要及完整来源链。详见[实测报告](../experiments/material-preview-binding/REPORT.md)和[复现入口](../experiments/material-preview-binding/README.md)。确认、改选素材、编辑与自动发布约定均明确标为实验注入，不是真人内容认可。

**来源固定为一次实际选中的字节版本，路径和文件名只保留为来源线索。** 原路径的 Excel 从合计 10 改为 16 后，旧快照仍可核对。实验明确让 A 改选新版并重新预览，B 保留自己原选的版本。A 的改选不改变 B；路径变化也不被擅自解释成用户要求改选。是否追随最新文件须来自本次委托或已有取材约定，变更实际选中素材后旧确认失效。

**确认批准的是完整的发布内容与范围，不能是一个独立的“同意”标志。** A 修改内容后，旧预览的迟到回复被拒绝；另一任务的回复、重复回复、停止后的旧授权均未恢复派发。A 的有效回复让 B 继续待确认。自动发布保留明确约定的版本并生成本次具体内容的授权；改目标、处理要求、素材范围或任务，以及撤销约定时，旧授权失效。所有校验都先于本轮网页写入；跨进程读取后再次校验。

后续持久化协议至少须保留这些关系，具体字段和存储技术由后续事项确定：

| 记录 | 必须能核对的关系 |
| --- | --- |
| 素材版本 | 原来源、选择依据与范围、选中时间、不可变字节及摘要；替换文件形成另一版本 |
| 解析结果 | 所属素材摘要、解析器及版本、工作表／单元格位置、原类型、值、公式与缓存／计算来源；空白不等于零 |
| 内容版本 | 所属任务与执行、所用素材和解析版本、处理要求版本、模型输入输出来源、事实或计算引用、最终标题正文与附件、父版本及编辑来源 |
| 确认或发布约定 | 发起任务与执行、参与请求身份和有效状态、被确认内容及目标范围；或明确约定的版本、素材范围、目标、处理要求与撤销状态；重复或过时回复不能重复生效 |
| 本次执行参数 | 固定流程版本、已批准内容版本、正文和目标映射、确切附件字节、所据授权及当前执行身份；参数不能在确认后静默替换 |
| 发布观察与结果 | 派发前页面事实、上传及提交尝试、实际记录／URL、结果对应内容与执行、公开正文和下载摘要、核对依据及不确定状态 |
| 核对结果 | 引用或数值核对、内容语义核对、页面准备、发布结果分别记录其版本与覆盖范围；任一单独成功不能替代其余保证 |

**实际产出与冻结内容一致。** A 发布新版合计 16 并保留修改的备注；B 独立发布原版合计 10；C 按注入的明确约定发布新版合计 16。公开正文逐字一致，三份下载分别与选中的原始文件逐字节一致。网站为 C 的附件加了文件名后缀，因此结果身份必须保留实际链接与字节摘要，不能只匹配原文件名。

本轮只证明当前小型样本的版本关系和实际结果，不证明任意生成文字的语义正确、复杂 Excel 解析、完整预览 UI、并发发布或崩溃事务。模型引用值经过核对，四份实际建议由 agent 逐项阅读，发布后再以原始表格独立断言；未用 JSON 格式正确替代事实判断。完整请求副作用关联仍由[网页动作、上传数据与写请求的关联边界](18-action-request-association.md)验证。最小事实已交给[执行记录、流程更新与定时恢复约定](10-durable-execution-contract.md)，本项解决，不扩建产品实现。
