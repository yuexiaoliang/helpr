## Question

用于首轮真实 AI 实验的现有模型服务、接口协议和模型是什么，接入后实际支持哪些调用、结构化输出、页面理解与并发条件？产品已决定使用用户现有 API，此事项补齐实验输入，不重新选择是否接入模型。

先核对用户已经提供的非敏感配置；缺失时仅向用户获取服务与模型信息及安全配置位置。凭据通过本机配置读取，不写进对话、地图、报告或 Git。

对实际协议做最小请求验证，记录工具或结构化结果能力、视觉输入是否可用、响应与限流行为，并区分已查文档和实测事实。按实验需要调用，不根据未经验证的服务宣传推断兼容性。

输出接入条件与最小可重跑验证方式，供后续 AI 探路与重放实验使用。更换提供方的产品约束保持有效；此事项不设计完整设置界面。

## Answer

**已取得继续首轮 AI 网页实验所需的真实接入条件。** 用户指定的 `deepseek-flash` 经官方 `https://api.deepseek.com` 的 Chat Completions 接口完成 8 项检查：文本、JSON、工具调用与结果回传、合成页面文本理解、截图读取、双请求重叠、流式输出、客户端取消。10 次真实请求均返回 HTTP 200。详细配置、结果、用量与局限见 [实验记录](../experiments/model-api/REPORT.md)，可重跑入口见 [实验说明](../experiments/model-api/README.md)。

**产品保留用户自行配置服务的要求，DeepSeek 只是测试阶段的选择。** 参考 OpenCode 与 Cline 后，后续设置方案采用“提供方预设 + 可编辑连接配置 + 独立凭据引用”的职责划分：常规用户在设置中选择服务、填写密钥，必要时调整地址和模型，完成连接验证后再使用；日常任务对话不要求选择模型。预设填写常见参数，自定义配置只展示已经实现的协议。具体设置界面、SDK 和正式凭据存储方式尚未选定，不把本机实验文件视为产品方案。

配置实践的资料依据为 [用户自行配置模型服务的实践](https://github.com/yuexiaoliang/helpr/blob/4fab6200cc1f0477a3c7189ae473ea7852c2d5c8/docs/research/model-configuration-patterns.md)，位于独立分支 `research/helpr-model-configuration`，提交 `4fab6200cc1f0477a3c7189ae473ea7852c2d5c8`，已推送但不合并。文档声明与实际验证分别记录；更改地址、协议、模型或相关选项后，旧的验证结果不能直接沿用。

**后续实验的输入已经就绪。** 非敏感字段位于 `experiments/model-api/config.example.json`，可复制为忽略提交的 `config.local.json`；凭据位于同目录 `.env.local`，变量名为 `DEEPSEEK_API_KEY`，权限为 `0600`。客户端可读取环境变量或此本机文件，凭据不会写进任务、流程或结果记录。相同测试用途可复用该配置，无需再次向用户索取密钥。

**通过范围有限且明确。** 当前探针采用非思考模式、512 输出 token 上限和合成样本；JSON 模式通过不代表严格 JSON Schema 通过，客户端取消不代表服务端停止计算或计费，两个 API 请求重叠不代表两个网页任务并行已经完成。思考模式、模型质量和具体浏览器执行器的适配由 [参数化流程的冷启动重放与修复更新](05-runtime-flow-replay.md)及 [可见工作区中的 AI 双页操作归属](06-ai-parallel-binding.md)按所选组合继续核对。

本项已解决。模型接入条件解除后续实验的依赖，最终技术组合与正式设置实现仍由地图和后续规格处理。
