## Question

用于首轮真实 AI 实验的现有模型服务、接口协议和模型是什么，接入后实际支持哪些调用、结构化输出、页面理解与并发条件？产品已决定使用用户现有 API，此事项补齐实验输入，不重新选择是否接入模型。

先核对用户已经提供的非敏感配置；缺失时仅向用户获取服务与模型信息及安全配置位置。凭据通过本机配置读取，不写进对话、地图、报告或 Git。

对实际协议做最小请求验证，记录工具或结构化结果能力、视觉输入是否可用、响应与限流行为，并区分已查文档和实测事实。按实验需要调用，不根据未经验证的服务宣传推断兼容性。

输出接入条件与最小可重跑验证方式，供后续 AI 探路与重放实验使用。更换提供方的产品约束保持有效；此事项不设计完整设置界面。
