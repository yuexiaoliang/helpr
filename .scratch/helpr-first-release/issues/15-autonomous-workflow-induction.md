# 验证无需人工修订的流程归纳与条件校准

## Question

前提：[验证流程适用性、步骤条件与修复边界](14-workflow-reliability-contract.md)。

当前流程可靠性实验暴露了新的明确缺口：模型整体生成或修订候选时，会混淆阶段、遗漏约束、抄写样本值或改错条件。分项提议、任务输入绑定及正反页面对照能改善候选，但最后的组合仍由实验驱动限定，并没有证明系统可以无人修订地形成可靠流程。

能否从明确的自然语言测试委托、素材与实际页面观察开始，自动形成目标输入、适用条件、步骤和结果规则，并通过有限的自我校准得到可用候选？实验中不能由维护者补写网站选择器、字段绑定、步骤条件或成功规则，再把结果计作自动学习。

## 需要取得的证据

- **目标约束来自委托**：区分用户给定的事实、系统建议和已经授权的要求；运行时期望值引用本次输入，不能由模型通过修改期望值或抄写样本来让检查通过。实验使用明确标记的测试授权，真实内容预览和确认版本仍由已有素材事项验证。
- **分项提议能够自动组合**：比较整体生成与较小提议的失败来源；记录规则对应的网页证据、参数来源和阶段。规则校准程序与网站数据分开，不为这个后台编写专用归纳逻辑。
- **条件经过正反例核对**：对至少一项关键条件，自动识别并保存满足与不满足时的证据。不能因模型输出 JSON 合法或复述“已检查”就晋升候选；反例不足时明确保留未验证范围。
- **适用性与效果分类有依据**：用同一网站上的相近但不同委托，检查是否会误选流程。改变候选对动作效果的声明，验证它不能仅靠将提交标为普通读取而绕过必要检查；无法识别的语义与副作用明确保留为限制。
- **换输入仍成立**：首次成功后，在另一组未用于修订的素材和文字上复用；同时覆盖不适用输入、易混淆常量与控件变化。记录正确自动完成、正确停止或需要参与、错误宣告成功，以及模型调用量和校准次数。

先限定在已准备的真实后台与小范围任务上。独立人工定义的测试断言可以评价结果，但不进入运行时决策。自动校准应有明确的时间和调用预算，失败时保留候选及原因，不无限尝试或直接对业务网站重放不确定提交。

输出实际自动完成范围、失败样本、建议采用的归纳与校准方式，以及仍需要用户参与或额外验证的部分。第二后台验证、完整自然语言产品交互和生产实现不由本事项代替。

## Answer

2026-10-10：完成对当前归纳方式的限定实验，**完整自动学习未通过**。本项记录否定性结论后收束，不表示自动学习能力已经成立。实际范围、原始失败和运行证据见 [实验报告](../experiments/autonomous-workflow-induction/REPORT.md)，入口见 [实验说明](../experiments/autonomous-workflow-induction/README.md)。

1. **不能把格式或模型自述当作可信条件**：五轮真实探索均在上传和发布前结束。反例包括字段值已经正确却反复填写、混淆动作前后控件名称和 frame、非法 JSON、格式修复再次失败，以及工具参数多包一层对象。原生工具调用在两次独立格式对照中有效，但实际闭环仍失败，没有形成或晋升完整流程。
2. **目标事实可以与模型提议分开保留**：输入通过自然语言原文引用和实际素材元数据建立来源，授权和输入摘要固定。新建公开附件、存草稿、修改已有文章、读取表格生成摘要四个相近委托的对照判断正确；该证据只涉及固定目标描述的匹配，不代表完整流程已经可用。
3. **受限观察提议取得局部正反证据**：程序从原 `fill` 动作固定相等语义和已绑定输入，模型仅提出实际观察位置。正文条件在填写前失败、填写后通过；未参与校准的另一组文字复用通过，执行期没有模型调用；控件更名后在正文写入前正确停止。维护者没有补写该观察定位。这是正文步骤及四步前缀的局部证据，没有验证上传素材、发布、下载或整条流程。
4. **已有约束可以阻止标签篡改，但不能替代首次判断**：借用旧实验候选的离线回归中，将提交改为读取被封存动作记录拒绝，修改已授权输入也被执行 Interface 拒绝。此回归不计作本轮自动学习成功，首次动作效果判断及未知副作用仍待验证。

建议验证“固定目标与动作语义、按阶段接受小提议、以实际正反状态校准”的方式。新建 [验证受限提议下的完整流程归纳](16-constrained-workflow-induction.md)，承接尚未取得的完整路径、上传条件、提交识别和保留集证据，继续阻塞执行组合选型及第二后台对照。没有把缺失的完整轨迹补成手写候选，也没有运行并声称通过完整候选比较。

共 54 次真实模型调用，已返回用量为 293,903 tokens；一次取消请求没有返回 usage，计费情况未知。实验驱动调整、预算调整、成功范围和未测项目均见报告，不从这组适应性实验推算生产可靠性。

## Comments

本轮只解决了对当前探索与归纳方式的评价，得到的是完整闭环未通过、受限字段提议值得继续验证的结论。最终技术组合仍未确定，已有产品范围与验收要求仍须由后续完整实现满足。
