## Question

前提：[参数化流程的冷启动重放与修复更新](05-runtime-flow-replay.md)、[可见工作区中的 AI 双页操作归属](06-ai-parallel-binding.md)、[人工接管的输入识别与让出操作](12-human-input-takeover.md)和 [流程适用性、步骤条件与修复边界](14-workflow-reliability-contract.md)。页面与输入对照已经取得事实；人工接管已取得 macOS / Electron 固定已登记视图中的真实证据，[页面变化后的输入归属与继续](19-page-lifecycle-input-ownership.md)仍需补充，不能由 AI 页面绑定或停止实验代替。

基于实际页面、输入来源、独立停止、AI 并行与流程重放证据，首版采用哪一套浏览器承载和执行组合，关键 Module 的 Interface 需要提供哪些保证？

[AI 双页实验](../experiments/ai-parallel-binding/REPORT.md) 已在两种宿主取得真实模型、显式 target、独立执行进程及逐原语停止的组合证据；验证对象是小型封闭动作执行器。它没有证明 Stagehand 或其它 SDK 的内部动作可取消，也尚未与完整发布流程合成。选择时需明确实际采用的执行器及未覆盖原语的处理，不能仅凭宿主相同把两组独立实验当作完整组合已验收。

比较已取得证据的方案，给出明确推荐和影响用户体验、维护成本及后续扩展的取舍。用已确认产品行为判断方案；需要范围变化时明确说明，不把未通过实验的能力默认为可用。

流程表示与执行机制的选择必须能承载已验证的适用条件、参数绑定、步骤条件、结果判定与修复限制；不能仅凭可以录制和重放动作就确定方案。提交恢复、内容版本和第二后台事项各自补充的证据仍须进入最终规格，不能由宿主选型替代。

[上传授权与完整流程的分阶段检查](17-upload-authorization-and-workflow-checks.md) 已在既有自动探索前缀上补全真实发布、模型位置校准及冻结后保留集，解除此前只有局部复用证据的缺口。这仍是单后台、单附件及有限任务形态的证据，不能直接推广为完整产品能力。

该实验还观察到目的未核实的写请求在点击等待窗口中被放行；上传文件选择与请求元数据的对应也不是传输字节证明。须结合 [网页动作、上传数据与写请求的关联边界](18-action-request-association.md) 的事实，确定执行 Interface 能提供的保证、必须停止或保持不确定的范围；不能把结果正确当作所有副作用均在授权范围内。

形成足以写规格的选型结论、必要的能力约定与仍需在实现中检查的限制。只有符合难逆转、需要背景解释且存在真实取舍的决定才写 ADR；文件结构和日常实现细节留给后续工程工作。

## Comments

2026-10-11，[取得第二后台的流程对照证据](11-second-backend-comparison.md)已完成。Drupal 七步流程及两份冻结后样本通过，但需要两次通用程序修订与一次模型结果位置校准。选型须承载原生选项标签条件、动态结果定位、后置错误的已执行事实，以及没有合格提议位置时的未知出口；不可将维护者诊断后成功表述为任意新网站原样自动成功。协议变化、负例、源码版本和未取得保证详见该事项 Answer 与实验报告。

2026-10-12，[人工接管机制验证](12-human-input-takeover.md#answer)完成受控范围：真人点击、中文输入、原生粘贴、对应任务让出和明确继续均有事件及用户反馈；工具样本单独标记。任意页面刷新或原生视图变化仍可能使归属失效，实际休眠恢复也未获验证。选择时必须结合新增前置事项的结果，不能把固定视图通过扩展为任意网站全生命周期可用。

2026-10-12，[网页动作、上传数据与写请求的关联边界](18-action-request-association.md#answer)完成 25 个受控场景。时间窗口、文件名、同一事件 / 调用栈和内容匹配均不足以证明授权归属；完整 HTTP 实体约束能拒绝替换字节和不符正文，但相同内容的旧请求仍可抢先消费新许可。page.route 还存在实测 service worker 和重定向覆盖缺口。选型必须明确首次学习如何得到适用请求约定、支持哪些观测通道、何时保持未知及停止派发、已送出时怎样核对；不能把本机 HTTP 代理的有限证据当作任意 HTTPS 网站或 Electron 组合的完整保证。是否接受候选限制及如何保持已确认自主执行体验属于本事项的真实取舍，前置实验没有替用户决定，也没有引入逐请求批准。
