# 08: 自动检查新版与可信下载提醒

Status: ready-for-agent
Blocked by: 02

**What to build:** 应用自动检查可信来源的版本信息，发现适合当前 Mac 的新版时提醒并提供手动下载入口；来源不可用或信息不适用时明确反馈。

## 前置交付与范围

只交付版本查询和下载入口，不下载包、不登记或安装更新。用户实际换版由 09 完成；无需等待 03–07 全部完成即可在 02 的设置与应用身份基础上实现。

前置事项：[02 配置模型并在所属任务理解网页](02-model-settings-and-page-understanding.md)。

## Acceptance criteria

- [ ] 确定并记录可维护的自用 HTTPS 版本来源、版本与架构识别方式及下载入口；不要求公开发布或立即取得付费签名身份。
- [ ] 应用运行时可自动检查并提醒，检测结果可在应用中查看；不抢任务焦点，也不把网络错误显示为已是最新版本。
- [ ] 检测请求只发送必要版本、平台、架构和兼容信息，不包含任务、素材、登录或模型凭据。
- [ ] 独立观察实际请求，确认检测不会下载安装包、登记待安装版本、缓存并自动应用，或调用带下载副作用的更新入口。
- [ ] 对来源异常、不可用、信息损坏、旧版本、不适用架构和数据兼容限制给出正确结果，不把不适用版本当可安装更新。
- [ ] 提供与可信版本信息关联的手动下载入口；打开链接不等于准备退出、批准网页发布或开始安装。
- [ ] 检测和提醒故障不破坏正在执行的任务；通过独立版本服务与实际应用界面核对正常、失败及隐私边界。

## 验证方式

走应用运行的版本检查入口，用独立服务记录完整请求和下载次数，再在实际应用核对提醒与链接。检测成功不能用手写状态代替网络行为证据。

遵循[总览中的跨事项完成约定](../README.md#跨事项完成约定)，从正式产品公开入口验证并保留独立证据；不把旧实验通过当作本项完成。真实运行沿用具体案例的有效授权与累计消耗上限，本事项的发布本身不启动新实验。
