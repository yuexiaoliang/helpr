# 18: 读取 Excel、预览并确认文章

Status: ready-for-agent
Blocked by: 13
Spec: [首版实现规格](../../helpr-first-release/spec.md)
Index: [实现事项总览](../README.md)
Engineering: [共同工程约定](../README.md#工程实现与验证约定) · [已确认选型](../engineering-stack-proposal.md)
User stories: 11–13、28、48

**What to build:** 用户委托读取选定 Excel，系统生成有依据的文章建议；用户在所属任务预览、修改并确认，再通过真实网页发布。

## 前置交付与范围

在素材版本、参与请求和真实发布之上增加通用表格理解与内容处理，不编写针对验收文件或栏目专用的业务实现。可复用发布约定由 19 接入，本项默认逐任务确认生成内容。

前置事项：[13 首次附件发布并保存学到的流程](13-first-publication-and-learned-workflow.md)。

本项原型阶段使用代表性文件比较成熟解析库，明确文件格式、公式缓存与重算、日期及缺失值等边界，再确定具体库和版本。原型需展示用户如何看到来源与无法确定的内容；读取缓存不能冒充重新计算，研究中的候选库尚未选定。此安排不减少首版 Excel 成文范围，也不自研通用解析器。

## Acceptance criteria

- [x] 读取固定素材版本，保存解析与处理要求版本及事实来源；数字和正文事实可回溯到源表位置，不使用来源后来改变的内容。
- [x] 实现遵循本项已确认原型确定的解析支持范围，锁定解析库及版本；代表性文件中的公式、日期、空值和不支持输入得到正确解释或明确反馈，不能把无法确定的值伪造为事实。
- [ ] 根据自然语言要求形成文章建议并在所属任务展示实际预览、附件和目标；不能把“委托发布”解释为所有生成内容已经被批准。
- [x] 用户可修改内容或目标，系统重新判断确认适用性；旧单次确认不能批准新版本，同一素材发往其它平台仍分别确认。
- [x] 确认绑定任务、内容、素材和目标，接受与资格变更原子保存；回执丢失或重开后保留仍有效的确认，不重复索要。
- [x] 发布时核对当前预览版本、实际网页正文、附件和目标；确认后内容被替换、新停止或目标改变时阻止旧派发。
- [ ] 独立逐项对照真实文章与源表事实和数字，并核对结果位置；文字生成正确不替代网页发布结果，网站返回成功也不替代内容一致。
- [x] 解析、预览、确认、提交和事实依据形成完整记录并进入备份／恢复；失败不伪造内容或将素材改为已完成。
- [ ] 覆盖内容不同的表格、修改后旧确认拒绝、跨任务回复、确认中断和实际发布；按批次分别记录内容模型使用与网页步骤模型使用。

## 验证方式

从正常内容委托与参与入口贯通，使用真实表格和网页产出。独立核验可读取源表与结果，不把期望文章、字段映射或选择器传给产品作为答案。

遵循[总览中的跨事项完成约定](../README.md#跨事项完成约定)，从正式产品公开入口验证并保留独立证据；不把旧实验通过当作本项完成。真实运行沿用具体案例的有效授权与累计消耗上限，本事项的发布本身不启动新实验。

## 开发结果

2026-11-07，按当前持续开发流程完成独立实现与可自动完成的检查，**6/9 条关闭**。首批解析支持与边界已比较、锁定并记录，没有为历史原型阶段表述等待额外批准。SheetJS CE 0.20.3／yauzl 3.4.0／saxes 6.0.0 读取固定 `.xlsx`；公式与不确定值不作事实。解析、要求、逐段来源、模型输入输出、文章父版及用户改稿进入格式 17 的持久记录与备份校验。旧确认、跨任务回复、改目标、新停止及正文替换均受现有统一入口约束。

最终 `pnpm check` 通过 257 项应用测试（含 14 项新增定向／UI）、9 项验证器、25 项旧回归及 225 源码语法、类型、lint、格式检查。固定签名候选 **68／excel-article-18**，启动 **187／188** 完成两份不同 Excel 成文、A 改稿后的旧确认拒绝、分别确认发布、原路径变化后的固定字节下载及冷开。独立 SQLite 与快照逐字段一致，原表数字与本机网站正文逐项核对，26 个已见自有 PID／6 个自有进程组全清空。2 次本机内容模型、15 次网页规划、3 次委托绑定；2 上传／2 草稿／2 发布，真实模型和远程写入为 0。失败及具体修正、最终检查见[报告](../../../docs/testing/evidence/article-18/REPORT.md)。
