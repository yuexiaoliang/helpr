# 01: 可安装的双任务真实工作区

Status: ready-for-agent
Blocked by: None
Spec: [首版实现规格](../../helpr-first-release/spec.md)
Index: [实现事项总览](../README.md)
User stories: 3、17、58、64、65

**What to build:** 用户在当前 Mac 独立打开 helpr，创建两项任务，分别查看真实网页和独立对话，手动登录；完整退出再打开，仍能找到同一任务和保留的浏览器会话。

## 前置交付与范围

这是正式应用的第一条完整路径。固定应用身份、数据位置和打包入口，使用实际页面与本机记录；本项只开放受控观察，不声称已有自主网页执行。其后事项在同一应用上继续扩展。

本项没有前置实现事项，可以推进原型与确认；用户要求每个功能的原型取得明确同意后才进入真实实现。

- 状态：待确认

- 确认记录：用户已给出 A／B 组合及移除重复入口的反馈；2026-10-14 的“那继续吧”用于补齐本项原型，不是正式实现授权。本轮行为提案尚待体验确认。
- 边界：本页只用内存模拟；真实安装、冷启动、持久记录、Cookie 保护、控制连接与宿主隔离仍需正式实现和独立验证。下列验收项没有因原型走查而完成。

## Acceptance criteria

- [ ] 在用户当前 Apple Silicon / macOS 14.8.3 上安装并独立打开，无需开发命令或关闭系统安全设置；依赖、架构、应用身份与原生组件构建方式有可核对记录。
- [ ] 从应用创建两个稳定身份的任务，各自显示真实网页、独立宿主对话和基本状态；输入、页面引用与会话历史不串用。
- [ ] 任务元数据和对话通过单一持久记录拥有者保存到本机 SQLite，数据独立于安装包；完整退出重开后保留身份，不凭空新建另一份工作。
- [ ] 用户可在真实网页手动登录并保留持久会话；明确会话共享范围，从首次建立资料区即启用和验证 Cookie 保护，不把整个浏览器目录当缓存或宣称全部加密。
- [ ] 控制拥有者持有私有 pipe，工作者通过受管连接仅取得已允许且归属正确的观察能力；不存在裸回环 CDP 旁路，外部、跨任务和未支持能力请求被拒绝。
- [ ] 远程网页使用 sandbox、context isolation 和 web security，不能获取 Node、模型密钥、任意本机文件或宿主命令；宿主对话入口核对发送方和操作角色。
- [ ] 权限、打开页面或保存记录失败时给出可理解反馈并保留可用资料；模型尚未配置时仍可使用本项手动工作区，不伪装任务已自动完成。
- [ ] 加入实际安装包与公开工作区入口的检查，覆盖双页归属、冷重开、网页与宿主隔离及拒绝路径；构建包、浏览器资料和凭据按 ignore 管理。

## 验证方式

经过工作区和应用运行的公开入口验证，观察实际页面、另一个进程重开的任务记录及系统进程。只读取已归属页面，拒绝越权的结果要从独立客户端验证。此时没有自动网页写入，不能用此项证明后续停止或恢复已经完成。

遵循[总览中的跨事项完成约定](../README.md#跨事项完成约定)，从正式产品公开入口验证并保留独立证据；不把旧实验通过当作本项完成。真实运行沿用具体案例的有效授权与累计消耗上限，本事项的发布本身不启动新实验。
