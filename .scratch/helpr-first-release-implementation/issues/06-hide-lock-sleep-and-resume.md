# 06: 收起运行、锁屏与休眠恢复

Status: ready-for-agent
Blocked by: 05
Spec: [首版实现规格](../../helpr-first-release/spec.md)
Index: [实现事项总览](../README.md)
User stories: 21–24、31、51、59、61

**What to build:** 用户关闭主窗口后任务继续，并可从菜单栏返回；锁屏和休眠时停止派发，解除条件后先核对。集中完成早期产品的一轮真人接管与系统生命周期核对。

## 前置交付与范围

使用前置事项的同一安装包、双任务、原生输入和恢复机制。定时计划尚未实现，本项不代替 20 的错过时间判断；不把真实休眠与锁屏混为同一个案例。

前置事项：[05 退出、意外退出与冷重开核对](05-quit-crash-and-cold-recovery.md)。

## Acceptance criteria

- [ ] 主窗口红色关闭按钮仅收起，保留真实页面、任务和菜单栏返回入口；两项合格任务在隐藏时继续推进，重新显示不丢现场。
- [ ] 锁屏与休眠分别持有暂停原因；唤醒但仍锁屏、先解锁但仍未恢复运行条件时都不派发。
- [ ] 全部系统暂停解除后先核对；原活动且结果明确的任务才续做，停止、待参与、接管或未知仍保持各自条件。
- [ ] 核对期间新的锁屏、停止或输入使旧核对失效；重复事件不启动并发恢复，核对失败保持暂停而非默认放行。
- [ ] 遵循 Mac 现有休眠设置，不自动阻止休眠，界面说明休眠期间不保证按时执行。
- [ ] 先自动核对实际包、窗口可见、页面绘制、任务推进、焦点和采集就绪，再给用户一次一个动作；未就绪先修正测试装置。
- [ ] 首轮约 10–15 分钟主动操作，分别取得点击、无需先点击的中文输入法、⌘V、锁屏与真正休眠证据；A 让出、B 继续，明确继续后文字保留。
- [ ] 真人与自动事件分开记录；实际超时、系统阻塞或失败保留现场和累计次数，不反复要求用户盲试，也不把人工关闭错误弹窗算自动通过。

## 验证方式

公开系统事件和派发入口的确定性次序检查，加上目标 Mac 实际安装包的人体操作与进程／网页观察。06 取得早期真人证据，23 在完整交付候选上再做第二轮。

遵循[总览中的跨事项完成约定](../README.md#跨事项完成约定)，从正式产品公开入口验证并保留独立证据；不把旧实验通过当作本项完成。真实运行沿用具体案例的有效授权与累计消耗上限，本事项的发布本身不启动新实验。
