## Acceptance criteria

- [x] 主窗口红色关闭按钮仅收起，保留真实页面、任务和菜单栏返回入口；两项合格任务在隐藏时继续推进，重新显示不丢现场。
- [x] 锁屏与休眠分别持有暂停原因；唤醒但仍锁屏、先解锁但仍未恢复运行条件时都不派发。
- [x] 全部系统暂停解除后先核对；原活动且结果明确的任务才续做，停止、待参与、接管或未知仍保持各自条件。
- [x] 核对期间新的锁屏、停止或输入使旧核对失效；重复事件不启动并发恢复，核对失败保持暂停而非默认放行。
- [x] 遵循 Mac 现有休眠设置，不自动阻止休眠，界面说明休眠期间不保证按时执行。
- [x] 先自动核对实际包、窗口可见、页面绘制、任务推进、焦点和采集就绪，再给用户一次一个动作；未就绪先修正测试装置。
- [x] 首轮约 10–15 分钟主动操作，分别取得点击、无需先点击的中文输入法、⌘V、锁屏与真正休眠证据；A 让出、B 继续，明确继续后文字保留。
- [x] 真人与自动事件分开记录；实际超时、系统阻塞或失败保留现场和累计次数，不反复要求用户盲试，也不把人工关闭错误弹窗算自动通过。
- [x] 真人输入证据关联 04 的原生识别、实际阻断、网页收件及自动效果，确认先让出再交付；记录进程停顿、系统事件重复或迟到回执不能解除更新的暂停。
- [x] 汇总 01 的启动／切换及 03 的双任务测量，在当前 16 GB Mac 的首个贯通包补齐持续运行并确定明确性能门槛；记录场景、版本和方法，网站／模型等待单列，23 据此复验。
