**What to build:** 用户明确约定以后按某套要求发布，产品复述并记住范围；符合条件的新内容可自动处理，用户可修改或撤销。相同素材是否已处理按约定、目标、版本和工作期次分别判断。

## 前置交付与范围

把已有单次确认和素材处理事实扩展为可复用发布约定与明确工作身份。定时轮次在 20 叠加，流程只决定做法、不授予权限。

前置事项：[18 读取 Excel、预览并确认文章](18-excel-article-preview-and-publish.md)。

## Acceptance criteria

- [x] 自然语言复述素材范围、目标和内容规则，保存用户明确接受的约定版本与适用条件；没有明确约定仍执行默认内容确认。
- [ ] 符合有效约定的新内容可自动发布，不每次重复确认；平台、栏目或处理规则超出范围时请求参与，而非套用旧约定。
- [x] 修改或撤销有可靠次序，临近派发重新校验；已撤销约定不可批准新动作，已经送出效果仅如实核对，不自动回滚或重发。
- [x] 素材工作身份关联取材／发布约定、目标、不可变版本及所需日期／期次，不仅使用全局摘要、文件名或路径。
- [x] 同内容改名或移动且仍在范围内、工作含义不变时不重发已完成 A；未完成 B 独立处理，不被 A 的完成跳过。
- [x] 明确要求再发一次形成新的工作意图；源字节改变形成新版本，但更新旧记录、另发或纳入下一轮仍依据约定，文件变化本身不批准发布。
- [x] 约定和完成事实变更原子关联，失败或未知不当从未处理；同一身份的并发领取、重复通知及旧授权被拒绝或返回既有工作。
- [ ] 约定、撤销、工作身份和最小完成事实进入备份、恢复与保留规则；用真实内容发布核对范围变化、去重和明确再发行为。

## 验证方式

经委托／约定接受、素材工作领取及网页执行入口，独立核对实际发送目标和次数。比较同名异内容、同内容异名、不同目标及期次，不能只检查数据库中的完成标志。

遵循[总览中的跨事项完成约定](../README.md#跨事项完成约定)，从正式产品公开入口验证并保留独立证据；不把旧实验通过当作本项完成。真实运行沿用具体案例的有效授权与累计消耗上限，本事项的发布本身不启动新实验。
