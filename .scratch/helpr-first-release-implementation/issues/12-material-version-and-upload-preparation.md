# 12: 固定素材版本并准备真实上传

Status: ready-for-agent
Blocked by: 06, 10
Spec: [首版实现规格](../../helpr-first-release/spec.md)
Index: [实现事项总览](../README.md)
User stories: 5–6、25、42、52–53

**What to build:** 用户用自然语言指定素材范围与目标，产品选定 Excel 固定版本，在真实后台自主完成上传和草稿准备；缺素材或选择不清时请求参与。

## 前置交付与范围

首条真实附件业务先贯通准备阶段，不在本项宣称最终发布或完整流程可重放。素材、网页检查和恢复依据来自实际观察；最终发布由 13 完成，完整中断矩阵由 14 扩展。

前置事项：[06 收起运行、锁屏与休眠恢复](06-hide-lock-sleep-and-resume.md)；[10 参与请求、确认与全局可操作提醒](10-participation-and-actionable-notifications.md)。

## Acceptance criteria

- [ ] 按用户选择的范围与取材规则确定文件，缺失、多义或访问被拒时在所属任务请求参与，不任取文件或扩大范围。
- [ ] 选定字节形成不可变素材版本并保留来源和选择依据；完成写入、同步及完整性检查后才提交记录引用，文件名和路径不是版本身份。
- [ ] 来源后来改变、同名异内容或参数被替换不能偷偷改变当前输入；上传仅取得本任务已获准的固定素材。
- [ ] 产品通过通用模型提议和受控网页能力自行定位并操作真实后台，不使用维护者选择器、预写流程或独立核验答案。
- [ ] 上传、草稿及编辑目标在取得稳定关联后及时保存，不等整段准备完成；参数、素材版本、当前目标和权限保持一致。
- [ ] 产品从实际执行形成可保存的准备后条件、目标定位和恢复观察依据，明示哪些已验证；不把模型标注“只读”当效果保证。
- [ ] 准备中停止、保存失败或效果不明时阻止后续动作；重开核对实际已上传或草稿事实，不盲目重传或另建重复工作。
- [ ] 独立从实际站点和下载结果核对素材字节及准备效果，同时检查额外结果与已观察到的异常；正确页面不能掩盖串素材。
- [ ] 新素材文件、目标证据和准备记录进入既有备份与恢复契约，并接入三组公开行为检查中的相应路径。

## 验证方式

通过委托、素材选择和网页执行公开入口，在明确授权的测试后台取得真实上传与草稿证据。独立站点查询及下载字节只供核验，不回灌给产品；模型、上传和草稿分项计数。

遵循[总览中的跨事项完成约定](../README.md#跨事项完成约定)，从正式产品公开入口验证并保留独立证据；不把旧实验通过当作本项完成。真实运行沿用具体案例的有效授权与累计消耗上限，本事项的发布本身不启动新实验。
