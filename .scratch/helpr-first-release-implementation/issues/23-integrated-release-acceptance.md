- [ ] 冻结应用、Node／pnpm、依赖锁文件、原生组件、数据／状态模型格式、模型配置和测试资料版本，核对干净冻结安装、实际包内容和依赖／许可证清单，建立完整证据索引；每批列出案例、独立判定、具体用量上限及停止／清理条件。
- [ ] 五项业务各至少两次独立成功，合计至少十个不同素材或输入样本；首次探索无预置业务流程，复用使用产品实际学得流程，同一输出不重复抵算其它场景次数。
- [ ] 五项分别覆盖首次附件发布、换输入复用、完整退出后的冷复用、Excel 成文预览确认、Drupal 不同后台；结果与附件字节、事实数字和任务归属独立核对。
- [ ] 探索＋探索、复用＋复用、探索＋复用均有真实推进交叠；A 接管／停止／待参与时 B 继续，第三项排队，隐藏窗口继续，不能以一项等待代替并行。
- [ ] 完成规格组合矩阵：任务组与历史、全局参与及重复回复、页面变化与未知输入、共享登录和目标、素材／确认／约定、定时、修复采用、中断、控制隔离及模型配置。
- [ ] 在目标安装包完成第二轮集中真人点击、独立中文和粘贴、锁屏、真正休眠及恢复文字核对；agent 先完成现场预检，用户还需确认实际流程可理解。
- [ ] 实际只读版本检测与两个真实安装版本的手动升级通过，保留原受保护凭据、未过期登录和全量业务资料；系统交互与失败分别记录，重填密钥或重新登录不能抵算。
- [ ] 完整资料的保存失败、空间不足、主动清理、备份及旧备份恢复通过；停止和较新约定不被旧快照覆盖，记录缺失不成为重发理由。
- [ ] 日常自动检查和所有受影响组合通过；确定性缺陷保留修前失败和修后证据，真实模型／环境失败保留原样，人工关闭错误弹窗不计作自动通过。
- [ ] 独立记录进程慢盘、退出及提交回执丢失／迟到不绕过即时阻断，状态恢复不重启副作用；AI SDK 没有预算外隐式请求，实际包中的迁移、原生依赖、受限通信及诊断轮转／脱敏均有证据。
- [ ] 原生识别、实际阻断、网页首次收到人工输入及自动动作效果的因果符合规格；不仅核对最终暂停状态。点击、中文输入法和粘贴、IPC 延迟、旧动作及页面变化覆盖各自适用范围。
- [ ] 在当前 16 GB Mac 复验由 01–06 贯通包建立的启动、切换、双任务资源和持续运行数值门槛，测量方法一致，网站／模型等待单列；没有基线或越过门槛不能以工具支持声明判为通过。
- [ ] 遇到重复发布、串任务、停止／恢复失效、未知最终结果、关键保存、凭据或控制边界问题、错误弹窗或进程残留时停止受影响验证并保留证据；未通过范围内要求阻止交付。
- [ ] 两次成功是门槛而非无限重试预算，准备失败及修后重跑累计；不重置旧实验额度、不擅自断电、不扩大到生产发布或购买签名服务。
- [ ] 交付当前 Mac 独立应用、实际版本和支持范围、安装使用步骤、运行条件、已验证证据及局限；自动安装仍延期，正式对外测试前的签名／公证工作另行安排。

## 验证方式

使用规格已确认的三组公开入口和前置事项的实际产品检查。独立核验代码与答案不进入产品学习／恢复路径，源码回放、真实网页、真实安装包、真人与系统交互各自标明证据范围。超出单次验证中可处理的缺陷给出具体修正范围，不以删样本或缩范围收束。

正常启动最终产物，通过 UI 共用的受限业务入口取证，保留正式隔离、Cookie 保护和关闭裸调试的配置；不使用会注入调试参数的启动器替代最终包验收。依赖升级的相关复验、性能基线与最终结果列入同一证据索引，按原批次预算执行。

遵循[总览中的跨事项完成约定](../README.md#跨事项完成约定)，从正式产品公开入口验证并保留独立证据；不把旧实验通过当作本项完成。真实运行沿用具体案例的有效授权与累计消耗上限，本事项的发布本身不启动新实验。
