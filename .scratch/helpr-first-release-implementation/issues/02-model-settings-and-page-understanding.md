# 02: 配置模型并在所属任务理解网页

Status: ready-for-agent
Blocked by: 01
Spec: [首版实现规格](../../helpr-first-release/spec.md)
Index: [实现事项总览](../README.md)
User stories: 1、2、4、16、64

**What to build:** 用户在设置中配置服务地址、模型和受保护凭据，在所属任务询问当前网页并得到基于该页的回复；更换服务后无需重建任务。

## 前置交付与范围

在 01 的实际工作区接入通用模型 Adapter 和任务对话。此项交付观察与理解，网页动作由 03 开放；测试提供方不是产品唯一服务。

前置事项：[01 可安装的双任务真实工作区](01-installable-task-workspace.md)。

## Acceptance criteria

- [ ] 配置服务地址、模型及凭据后，从任务对话发起真实网页理解请求；正常任务无需再次选择模型，服务切换保留任务资料。
- [ ] 模型收到与该任务绑定的页面观察、会话和执行上下文；两项请求及流式输出不串任务，不把当前激活标签页当回复归属。
- [ ] 模型凭据使用 macOS Keychain 支持的受保护路径保存；不可访问时保留受保护数据并暂停依赖请求，不降级明文。
- [ ] 普通日志、错误、流程与业务导出不包含密钥或认证头；错误服务回显凭据及重定向到其它认证目标均不能造成泄漏。
- [ ] 公开请求入口校验配置与支持能力，区分认证、连接、超时、格式及能力不足；不把失败空回复当任务完成。
- [ ] 请求支持逐任务取消，A 取消后不再消费其迟到流式内容，B 仍可继续；调用次数、并发和消耗上限在统一入口生效。
- [ ] 请求前保存必要用量预留，中断或缺少 usage 的请求保留未知消耗；换输出位置或重开不清零，重复回执不能重复记账。
- [ ] 受控服务检查实际请求、流式分块、取消和失败；真实服务验证按独立有界方案进行，受控响应不充当理解质量证据。

## 验证方式

通过模型请求和所属任务对话的公开入口，使用可计数的受控服务核对请求与取消，再以真实网页观察核对接入。受保护凭据只使用测试值取得存储证据，真实密钥不出现在证据中。

遵循[总览中的跨事项完成约定](../README.md#跨事项完成约定)，从正式产品公开入口验证并保留独立证据；不把旧实验通过当作本项完成。真实运行沿用具体案例的有效授权与累计消耗上限，本事项的发布本身不启动新实验。
