## Acceptance criteria

- [x] 一句多目标委托可形成独立任务并归入任务组，各自拥有会话、进度、内容／参与与结果，不共享一次内容确认。
- [ ] 已完成、已停止或以失败结果结束的任务点击关闭直接进入历史，保留对话和已产生结果。
- [ ] 执行、排队、待参与或接管的任务点击“×”时在标签页旁给出收起／停止及相应说明，不把关闭默认为停止或继续。
- [ ] 点外侧或 Esc 只收起提示，保留原任务状态；停止不作默认焦点或 Enter 的隐式选择，明确停止直接执行且不二次确认。
- [ ] 提示出现期间状态改变时按最新事实处理，不用旧提示启动、停止或关闭另一项执行。
- [x] 收起仅改变展示，真实页面和原运行／等待／接管状态保留；固定活动入口与提醒可返回，不能销毁页面来模拟保留现场。
- [x] 从历史重新打开只查看，明确继续后先核对；已完成不重发，有合格剩余工作才恢复活动入口。
- [ ] 关闭操作及重开后仍保持任务身份、结果和参与归属；以受控实际任务检查各种状态、误点和竞争。
- [ ] 切页、收起和历史返回后对话草稿、中文输入及焦点归属正确，旧视图订阅和迟到投影不覆盖当前任务；局部组件重建不恢复网页执行。

## 开发结果

从新建任务输入“把周报分别发到网站 A 和网站 B”，创建前可看到识别的目标，也可以保留为一项任务。明确并列的中文目的地按本机规则识别；有先后关系或超出识别范围时保留整句。每个子任务保存自己的目标、网页、草稿、内容确认与结果，组名取原委托。

活动任务的关闭提示贴在标签旁，收起后可从顶栏活动任务或待办返回。明确选择停止时，在同一次记录提交中停止并收入历史。已结束任务直接收入历史，历史入口只恢复查看。已完成且有同一目标版本的核对结果时，继续会显示该结果。已停止的任务明确继续后先核对，确认还有工作或需要参与时恢复活动入口。

实机验收与事项 10 合并。在 B 写一段未发送的中文草稿，点 A 的 × 后按 Esc，再打开并收起 A，从活动任务返回，检查焦点与草稿。关闭结束任务后从历史查看结果。预期输入法选词只完成输入，Esc 只收回提示，回看只打开原任务。若遇到真实登录或系统授权弹窗，在该处停止。
