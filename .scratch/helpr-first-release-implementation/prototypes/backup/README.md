## 打开体验

直接双击本目录的 [backup-prototype.html](backup-prototype.html)，无需安装依赖或启动服务。也可使用已打开的内置浏览器临时入口：<http://127.0.0.1:4320/backup-prototype.html>。

临时服务仅监听 `127.0.0.1:4320`，2026-10-23 12:29（Asia/Shanghai）自动关闭。关闭后 HTML 仍可独立打开；刷新会清空演示状态。

优先体验右侧的「02 恢复较早备份」：按绿色按钮逐步推进，观察 A 的较新停止保持、B 在网站已经完成的两次写入被补记，然后仅选择 A 继续。左侧「备份与恢复」和顶部任务标签也可直接操作。右侧「自由操作与故障模拟」可在任意次序停止、改目标、核对和推进。

800 像素及以下，指南排在工作区下方，可纵向滚动或用顶部按钮收起。任务和场景标签支持左右方向键、Home、End。

## 本版回答的问题

恢复旧备份后，如何保留较新的意图和已发生的结果，并让用户在逐项核对后选择继续？沿用已有浅绿标签栏、真实网页区域与独立任务对话的视觉结构，新增本机资料设置入口。

| 场景 | 体验重点 |
| --- | --- |
| 01 创建备份 | 本机位置、内容清单、排除密钥和登录、完整性检查后才成功 |
| 02 恢复较早备份 | 检查→保留当前资料→切换→逐项核对；较新停止不丢，B 已有结果不重发 |
| 03 目标已经改变 | 保留新目标，核对中的新停止使旧核对失效 |
| 04 在新环境恢复 | 当前没有任务；不默认旧意图有效，补模型设置和登录仍不自动继续 |
| 05 网站结果不明 | 无法唯一核对时保持暂停，明确继续也不允许重写 |
| 06 损坏与不兼容 | 校验错误、格式不兼容、旧状态无法迁移、引用文件缺失分别拒绝切换 |
| 07 空间不足与缺失 | 备份失败不显示成功，不删除其它资料 |
| 08 当前资料存不下 | 恢复前保留失败则不切换，自动工作仍暂停 |
| 09 慢备份时停止 | 已选快照与后来停止分别保留；A 停止，B 仍可推进，备份回执不放行 A |
| 10 保存后回执丢失 | 显示待核对回执，检查原备份，不重复创建 |
| 11 备份途中中断 | 记录不可用时暂停依赖工作；停止仍阻断，连接恢复不直接派发 |
| 12 恢复途中中断 | 当前副本先保留；演练切换未完成的中断路径，连接恢复后确认并重新切换，仍不自动执行 |

## 模拟边界

- 单文件、无依赖；两个 `script` 分别承载纯状态模型和页面。全部状态在内存中，模型不访问 DOM；页面不连接产品服务。
- 本机位置、文件快照、清单、校验、格式／状态版本、保存回执、记录进程、模型设置、登录及网站结果都是显式模拟。没有实际读取或写入数据库、业务备份、凭据和网站，也没有模型调用。
- 指南、自由操作和标有「模拟」的阶段按钮供观察状态。左侧「核对实际结果」合并模拟只读核对与返回；正式产品由系统自动处理相应阶段。
- 「网站结果」是独立的虚构计数，不随备份恢复减少；这不能证明产品已具备真实网站的自主核对能力。
- 本版覆盖当前已有任务、意图、动作及必要证据的备份契约；流程、真实素材版本与定时计划随后续事项扩充。应用版本回退与资料恢复分别说明，不承诺备份整包自动加密。
- 记录中断只是状态演练，没有真实杀进程或断电。切换中断仅演示保留原资料、未完成切换的路径，不能充抵实际迁移或提交不确定性检查。
- 用户确认本版仅代表同意所列交互与行为作为实现依据，不等于 07 的实际备份、完整性、凭据排除或恢复验收通过。

- 首轮完成 12 个场景的 74 个分步按钮，保存[完整末态与操作记录](evidence/walkthrough-first.json)。
- 修正新环境虚构当前任务和丢失回执却提前标「已核验」的呈现，定向复走 04、10，见[复核记录](evidence/walkthrough-followup.json)。
- 按任务分别接受核对结果，拒绝新的停止之后返回的旧核对；记录不可用时不接受结果。左侧逐项核对 A、B 后，A 保持停止、B 补记完成，见[实际浏览器画面](evidence/desktop-restored.jpg)。
- 位置输入的首轮发现：清空后点击仍采用旧值；保留原失败，改为在输入时更新模拟值。空路径拒绝和自定义路径保存复核通过，见[失败与修正](evidence/location-final.json)。
- 默认 1280 × 720 和 800 × 720 布局、指南收起、方向键任务／场景切换已走查。800 像素下文档宽度同为 800，无横向溢出；指南与工作区纵向排列，见[窄窗口工作区](evidence/narrow-workspace-800.jpg)和[窄窗口指南](evidence/narrow-800.jpg)。临时 viewport 已恢复。
