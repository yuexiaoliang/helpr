## 五项视觉检查

| 项目 | 核对结果 |
| --- | --- |
| 字体 | 使用系统中文无衬线字体，正常字重；标题、就绪状态与关闭按钮同一行。长目标省略显示，完整目标仍在可访问名称、标题和卡片中。品牌字形因参考为生成图存在轻微差异，可后续统一正式字体，属 P3。 |
| 布局 | 52px 顶栏，白色选中页签向下与网页相连；没有胶囊外框、下划线或任一小竖线分隔。未选中标签直接落在浅色底上。网页原有内容、地址栏及对话不因这轮改版增加高度。 |
| 颜色 | 浅灰绿 `#eff5f2` 顶栏、纯白选中项、深色标题、绿色就绪、灰色关闭。保留原型中需要补充信息的区别提示，不把其它状态都写成就绪。 |
| 素材 | 顶栏图标使用 Phosphor 原始矢量，网站标记使用 Simple Icons，无拉伸、破图和外网依赖。参考中 Drupal 的示意字母 d 换为同尺寸的库内 Drupal 标记；这是素材规范化差异，不改变标签结构。 |
| 文案 | 两项示例的短标题与参考一致；原始目标和身份仍保留。单独列出“就绪”，全部任务入口显示数量；没有下箭头或卡片底部“查看任务”入口。 |

## 交互核对

- 切换 A／B 会改变选中标签、网页和独立对话，各自未发送草稿保留。
- 悬停约 280ms 出现对应卡片，不切换当前网页；移出收起。键盘 ↓ 查看、Esc 收起、Enter 切换均可用。
- 顶部 ＋ 打开原有单目标面板，创建后分析或补问留在新任务。网站信息不足显示“待补充网站”，没有被压缩成“就绪”。
- 800 × 900 下，两项标签及新建、任务列表、退出均可见，整页没有横向溢出；第三项仅在标签容器内滚动，当前项完整可见。
- 600px 额外检查中浏览器标签连接两次失效；该次原生截图还发生缩放，因此不把 600px 作为已完成的视觉验收。本轮通过范围为桌面与 800px 窄窗口；恢复到常规预览后交付。
- 最终页面未报告控制台错误或警告；两个内嵌脚本与预览服务语法检查通过。
