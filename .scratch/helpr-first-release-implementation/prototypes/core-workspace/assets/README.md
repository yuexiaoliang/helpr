# 原型图标来源

顶部标签栏使用以下库的原始 SVG，复制到本目录供本机离线预览，不修改路径、不加入运行时依赖。

- `plus`、`x`、`squares-four`、`sign-out`、`globe`、`warning-circle`：[Phosphor Icons Core](https://github.com/phosphor-icons/phosphor-core)，npm `@phosphor-icons/core@2.1.1`，regular 样式，MIT；许可证见 `PHOSPHOR-LICENSE.txt`。
- `wordpress`、`drupal`：[Simple Icons](https://github.com/simple-icons/simple-icons)，npm `simple-icons@16.35.0`，CC0；许可证见 `SIMPLE-ICONS-LICENSE.md`。这些网站标记仅用于模拟后台，不表示合作或背书。

范围只覆盖本轮重做的标签栏；网页模拟和对话中的原有图标保持原型行为。
