# 收起、锁屏与休眠状态演示

版本：`lifecycle-v1`。这是事项 06 的原型，等待用户体验与明确确认，尚未进入正式实现。

双击同目录的 `lifecycle-prototype.html` 即可体验，无需安装依赖。所有系统事件、网页、对话与结果都在内存中模拟；不会实际锁屏、休眠或更改 Mac 设置。

## 要回答的问题

沿用 01–05 的双任务标签栏、真实网页区域的模拟外观与独立浮窗对话，检查窗口收起是否影响任务执行，以及锁屏、休眠与运行条件分别解除后，系统如何先核对并保留各任务原意图。不是重新设计工作区，也不把演示当作真实操作证据。

## 体验方式

1. 打开文件后，选择指南中的场景，按绿色按钮逐步体验。切换场景会重置为同一个初始状态。
2. 指南与状态表可滚动；展开“自由操作”后，系统事件、推进与核对返回可以按任意次序触发。演示没有计时器，因此系统暂停、核对和推进由这些按钮分步呈现。
3. 关闭指南可以完整查看工作区。点击红色关闭按钮收起模拟窗口；顶端的模拟菜单栏可返回。直接填写网页会让所属任务保留人工接管状态，文字跨收起与返回保留。
4. 两项任务分别显示原意图、进度、本次写入次数、核对在途／失效／留档与页面归属。切换任务或普通聊天不会接管网页。

## 场景与拟确认范围

| 场景 | 观察重点 |
| --- | --- |
| 收起运行 | 两项隐藏推进，菜单栏返回保留现场、进度与对话 |
| 锁屏暂停 | 锁屏阻止新派发，解锁先核对 |
| 唤醒仍锁 | 唤醒只解除休眠，锁屏条件独立保留 |
| 条件未齐 | 先解锁、后唤醒仍须等控制条件就绪 |
| 停止与接管 | 系统恢复不覆盖原意图，明确继续仅作用于对应任务 |
| 参与与归属 | 原参与回复与页面识别分别处理，识别后不自动恢复 |
| 核对中打断 | 新停止、人工输入、锁屏撤销旧核对；旧观察只留历史 |
| 失败与未知 | 核对失败不放行，先前在途效果可能迟到，未知不重发 |
| 重复与迟到 | 重复系统通知不并发核对，记录不可用时阻断，恢复后仍尊重新停止 |

以上行为拟作为 06 的正式实现依据。窗口关闭与任务标签页关闭不同；本原型只覆盖前者。退出／冷重开沿用 05，定时计划和错过时间归 20，均不因本原型扩展。模型、进程、网站、数据库、可靠保存和全部系统事件为内存模拟。没有模拟真人中文输入法或真实 ⌘V，工具填写不能充抵真人样本。

原型内附后续真人核对的安排：先确认实际包、窗口、网页绘制、双任务进度、焦点与采集就绪，随后一次一个动作、说明停止位置，预计主动操作 10–15 分钟。真正锁屏与休眠分别取证。持续运行测量与性能门槛待实际组合确定，本次没有填入虚构数字；原型批准也不构成追加真实运行预算或验收通过。
