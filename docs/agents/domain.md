# 领域文档

本仓库采用单一上下文布局：`GLOSSARY.md` 位于仓库根目录，架构决策记录（ADR）位于 `docs/adr/`。

## 探索代码库前先阅读

- `GLOSSARY.md`：了解领域术语。
- `docs/adr/` 中与当前工作涉及范围相关的架构决策记录。

若这些文件不存在，直接继续，无需提示缺失。`/domain-modeling` 技能会在术语或决策确定后按需创建。

## 文件布局

- `GLOSSARY.md`：领域术语及其定义。
- `docs/adr/NNNN-<decision>.md`：按编号保存的架构决策记录。

## 使用术语表中的名称

在事项标题、重构建议、假设或测试中命名领域概念时，使用术语表已经定义的名称。

若某个概念尚未收录，先考虑能否使用现有术语；若确有缺口，记录下来供 `/domain-modeling` 处理。

## 明确指出与 ADR 的冲突

若拟议变更与现有 ADR 矛盾，明确指出对应的 ADR，并解释为什么需要重新考虑该决策。
