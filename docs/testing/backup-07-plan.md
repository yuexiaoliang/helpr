# 07 本机备份与旧备份恢复

实现依据：[07 事项](../../.scratch/helpr-first-release-implementation/issues/07-local-backup-and-restore.md)及用户于 2026-10-23 明确确认的 `backup-v1`（`9bca802`）。本轮实现基点 `27be3b7`。

## 已确认的检查入口

沿用规格的三组公开入口，不增加新的测试分层：记录拥有者的备份／恢复与意图、应用协调服务、UI 与真实网页执行。源码检查使用临时资料、真实 SQLite 和实际备份文件；进程检查经过编译后的记录进程 RPC。模型替身和文件系统故障仅证明相应边界，不当作实际应用或业务能力通过。

目前业务备份为单个 `.helpr-backup` 文件，格式 1、记录格式 6、执行状态模型 1。事务内取得已有任务、执行、动作、请求身份、会话和模型用量的一致逻辑快照；清单包含内联 `records.json` 的字节数和 SHA-256。当前必要证据均在记录中，没有外部素材引用，新增资料类型须随所属事项扩展清单与恢复检查。上限 64 MiB，超过时说明并保留原资料；不截断或显示成功。

模型密钥、认证头、服务配置、浏览器资料、登录会话和临时执行资格均不导出。模型历史通过不含服务配置的历史记录保留，未知用量预留与原请求身份不能因恢复重置。升级至记录格式 6 前在原资料目录保存内部 SQLite 副本；该内部迁移副本与用户选择的业务备份分别处理。

恢复先检查输入，控制拥有者立即撤权、取消在途工作并保存暂停，再由记录拥有者保留当前业务副本并在短事务中导入。相同任务保留当前较新的完整记录，不用旧消息或目标覆盖当前资料；备份中本机没有的任务恢复进来。恢复回执与导入同事务，重送不重复导入。原停止保持，已派发未知事实保留，所有恢复执行先只读核对再逐项选择。只读核对经过既有观察和模型入口，不建立网页动作工作者；停止、原生撤权及版本变化使旧核对失效。

## 当前结果

实现提交 `baa4858`，两项超时审阅修正 `9435af5`；生产代码包含于候选 35。最终 `pnpm check`：94 项正式检查、25 项旧回归，类型、ESLint 与格式全通过。两轴审阅发现的“同一恢复在途返回 BUSY 后释放屏障”和“外层超时后 working 界面另建身份”均先取得失败反例，再修正并复核。

新增确定性证据包括：同身份恢复加入原 Promise；BUSY／回执丢失保留原身份与屏障；working 持续取得原操作终态；原生先撤权、异步通知后到的核对失效；新环境保留模型历史和未知用量；已派发未知动作不能继续，核对已完成后不重发。真实 Node 记录进程还经过 IPC 丢弃备份回执、SIGKILL 后重开核对原字节，以及用既有只读 SHARED SQLite 夹具阻止副本回执提交，观察到 `.partial` 写入后终止／重开核对。IPC 检查确认过滤器实际丢弃一次回执；中断检查确认 pending 为 `PROCESS_DISCONNECTED`、重开执行版本未变化，再以同身份恢复，避免把已提交后终止误记为切换中断。所有资料均为临时虚构资料，不修改产品数据库制造成功。

实际签名候选 35 的原生目录／文件选择、创建早备份、停止并修正 A、手动产生 B 已有网页结果、保留当前副本、恢复与逐项只读核对、仅明确继续 A、冷重开均已有 CUA 和独立接收端证据。A 的新目标与停止在恢复后保留；只读核对阶段 A0/B1；选择 A 后 A1/B1；冷重开 0 新模型／效果。清单字节、SHA-256、业务内容和排除项独立读取核验，恢复前副本含较新的 A 目标。见 [结构化记录](evidence/backup-07/RESULT.json)、[原生文件选择](evidence/backup-07/native-file.png)、[只读核对与明确选择](evidence/backup-07/reviewed.png)、[A 完成](evidence/backup-07/completed.png)、[冷重开](evidence/backup-07/cold.png)。受控模型与本机网页只证明对应的备份／控制路径，不延伸为真实模型能力、有效登录或跨换版凭据连续性。

主轮 89 在真实 UI 正常退出 `code=0` 时，验证器将并发 snapshot 的 `APPLICATION_EXITING` 误判失败，原报告不改写。脚本修正后只用既有剩余启动 90 补冷核对：保留原资料、端口、累计 6 模型／2 效果和原 20 分钟期限；网站接收器重启并载入已有计数，0 新请求／效果。两次正常退出后独立 OS 检查全部已见 PID／进程组为空。累计现为 35／8／90／37／17（构建／安装／启动／故障／清理），没有替换正式安装，候选 35 保留。

## 保留的验收缺口

慢保存、空间不足、记录中断与恢复中断的实包界面组合尚未执行。源码、真实 Node 记录和 React 回归不能代替这些实包证据；事项第 3、8、9 条暂不关闭，09／22 对 07 的依赖不解除。原失败、所有累计消耗及已通过主路径保留，不重做已通过的输入法、锁屏、休眠或网页效果。
