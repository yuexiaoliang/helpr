# 事项 13 验证安排

2026-11-06。按最新仓库约定推进独立实现与隔离检查。事项 12 的真实模型／WordPress 前置仍未整体解除；本安排不授权真实模型费用、远程上传、草稿或发布。

## 源码与本机公开入口

定向入口：`pnpm exec vitest run tests/workspace/publication.test.ts`；完整入口：`pnpm check`。

覆盖附件／目标／内容确认绑定、缺少下载证明拒绝提交、下载期间停止、预留后停止、已发布但结果不符保持未知、异常记录、结果与素材处理／流程同事务保存、提交失败回滚、重复请求、备份和冷开引用、格式 11 → 12 迁移。旧的草稿恢复仍不能由模型的 `complete` 直接变成完成。

实际签名包使用 `pnpm validate:workspace --fixture --candidate=publication-13-final --publication`。一次受管应用运行正常退出后再冷开；总时限 120 秒，准备和发布阶段各最多 50 秒，独立 GET 最多 5 秒。产品只读结果核对每次 GET 最多 8 秒、公开页最多 2 MiB、附件最多 8 MiB，无重定向或隐式重试。一次主路径最多 14 次本机替代模型、1 上传、1 草稿、1 发布；失败先保存记录和自有进程信息，有具体修正才另起一轮。

验证器从空资料与公开委托／设置／确认入口开始。网站和替代模型属于明确标注的本机夹具：它们检查真实字节、Playwright、隔离包和可靠记录组合，不能证明真实模型自主探索。产品中没有 WordPress 或夹具业务步骤。独立站点记录上传、草稿和发布次数，并对下载逐字节比较。冷开后核对结果、素材处理和流程引用，没有新网页写入。最后以 OS 检查自有 PID／进程组，保留所有原始失败和累计账本。

网页交互和真实 Electron 窗口的证据分开。Computer Use 无法连接时只保留原生窗口检查，不阻断脚本可完成的独立核对；不使用 agent-browser。

## 实现边界

每次附件发布均明确预览确认，绑定固定素材、稳定编辑目标、附件链接、栏目和全文；本项不建立长期自动发布约定。最终点击前另行下载比对固定摘要和长度，再取新的页面观察，并沿原统一预留／派发和原生输入资格检查执行。公开结果与下载通过才把该动作确认为完成。

结果核对使用未登录的 HTTP GET 和 HTML 解析，只支持同站、无需重定向且可直接读取的公开页和附件。HTML 核对排除脚本、注释、隐藏属性与表单值，有限检查全文、栏目和唯一附件链接；不执行页面脚本，不冒充完整 CSS 可见性或所有网络副作用监测。解析使用已锁定的 `parse5@8.0.1`，接口依据 [parse5 官方文档](https://parse5.js.org/functions/parse5.parse.html)。私有附件、动态公开内容或证据不足保持未知。

流程由本次已核对动作形成，保存固定版本、摘要、父版本、参数来源、步骤前后条件、结果规则、恢复地址和证据。仅表示原输入获得过验证；不凭一轮成功声称不同输入复用已通过，也不通过流程授予发布权限。缺失步骤条件的旧执行仍能保存已核实业务结果，但不会制造流程证据。
