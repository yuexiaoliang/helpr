# 18：Excel 成文与逐任务确认检查

2026-11-07，按当前直接实现、自主验收、本地提交及串行新聊天流程推进。直接前置 13 的真实模型／WordPress 检查仍待验，不能由本机替代模型解除。解析选型见 [Excel 解析调研](../research/excel-content-parsing.md)。

## 支持范围

固定素材不超过 8 MiB；只接受未加密 `.xlsx`。锁定 SheetJS CE 0.20.3 官方版本化 tarball，yauzl 3.4.0 逐项解压计数，saxes 6.0.0 核对有限的 OOXML 公式标记和工作表关系。没有自研表格解析器或文件／栏目业务映射。

ZIP 最多 1000 项、解压合计 16 MiB；最多 20 张表、合计 2000 个矩形范围内的位置，每表最多 2000 行／100 列，解析投影最多 100000 字符。超限整份拒绝，不截断后成文。SheetJS 读取放在 8 秒、128 MiB 老生代堆限制的工作线程，结束后终止线程；记录拥有者仍能响应停止。限制是当前支持范围，不代表可用来处理任意大型或恶意文档。

保留单元格原类型、原值、显示值、格式、地址、公式、合并主格和状态，明确 1900／1904 日期系统。公式不重算，缓存一律不作为确定事实，缺失缓存不显示为零；有限 XML 核对防止缺失共享主格时公式标签静默丢失。1900 日期序号 60 不变成公历事实。空白、空字符串、零、false、错误分别记录。隐藏内容及合并从属格不可作为事实；不刷新外链。旧 `.xls`、`.xlsb`、宏、CSV、外部连接及加密输入明确反馈；图表、图片、批注与格式布局不参与成文。

## 自动检查

- `pnpm exec vitest run tests/workspace/article.test.ts tests/workspace/article-ui.test.tsx`：两份不同业务数据；同一组 1900／1904 边界表；外链、尺寸与膨胀 ZIP；原路径改变后仍读固定副本；引用或数字不符拒绝；改稿新版本、旧回复／跨任务拒绝；停止与改目标；确认回执重送和冷开；备份与引用；真实本机 HTTP 的正文／目标／附件核对；来源预览与改目标交互。
- 夹具由 `tests/workspace/fixtures/excel/generate.py` 使用 Python 标准库构造真实 OOXML，不用被测库生成期望。公式缓存故意写成 999，必须排除。业务源码不含这些标签、数字或字段对应关系。
- `pnpm check`：严格类型、lint、格式、全部应用／验证器／旧回归；保留初稿失败及修正。

## 固定包轮次

候选 `excel-article-18`，命令 `pnpm validate:workspace --fixture --candidate=excel-article-18 --article`。一次受管应用、隔离资料、虚构本机 key 与临时网站；总时限 120 秒、阶段 50 秒、稳定准备最多 8 次。只预留一构建、一轮首次／冷开验证，失败先保存并收束，具体修正后才安排新轮次。

从公开委托入口读两份 Excel，分别成文并请求确认。A 修改全文后验证旧确认拒绝；A、B 在预览后改变原路径字节，发布仍引用各自固定版本。独立 GET 核对公开正文、栏目、附件字节和唯一发布；正常退出后核对自有 PID／组清空，再冷开比较来源、文章、确认和结果。确认由脚本通过产品公开入口提交，不冒充用户本人认可。内容模型与网页规划／委托绑定分别计数。
