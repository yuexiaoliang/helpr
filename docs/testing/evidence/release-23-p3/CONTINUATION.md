## 发布依赖

旧版生产依赖树中，React Aria Components 引入了 `client-only`。其浏览器默认入口 `index.js` 为零字节。将 React、React DOM 和 React Aria Components 移至构建依赖，继续用原锁定版本编译界面。打包器按实际输出的 11 个界面依赖加上生产依赖树生成许可证清单，发布预检从签名 ASAR 读取编译记录并重新核对随包材料。

候选 113–115 的主进程、宿主、预加载和界面共 18 个输出文件与 112 逐字节一致。新包的两层 ASAR 均无 `client-only`，已编译代码没有引用，发布许可证缺口为零。该包仍作为构建依赖留在锁文件中，旧候选的上游声明缺口继续留档。

从干净提交和空依赖目录验证冻结安装。锁文件仅移动三个入口的依赖分类，保留解析版本与完整性。Electron 44.7.2 复用已与官方摘要核对的本机分发档案。一次锁更新尝试因远程元数据超时而收束，随后离线冻结安装通过。构建 114 后发现渲染依赖清单的路径取值触发 TS2345。修正并通过类型检查后从干净提交 `7301bba` 构建 115。依赖输入和包布局与 114 相同，签名、包内容及许可证预检通过。
