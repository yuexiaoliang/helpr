## 已实现行为与边界

网页宿主提供实际 Electron Session、网站来源和启动／变化代次。Cookie 按实际 domain 影响已观察网站；控制拥有者用独占协议会话监听共享 localStorage 与 IndexedDB 的变化，只传来源，不保存键值、数据库内容或凭据。收到变化先撤销相关原生输入门、网页操作和模型资格，再保存逐任务的重新核对条件。旧代次、旧运行及迟到回执不能恢复资格；其它网站保留自身资格。

账号、稳定目标和权限由当前页面的结构化链接与原文提出。账号链接须唯一且同站，目标链接须唯一并等于当前完整编辑 URL，权限文字须实际可见。缺少证据时保守占用整个网站；不会仅按标签页、路径或同名文件推断独立。这是有明确编辑链接的当前能力，不能推广为任意网站或跨站 SSO 的身份识别。

同 Session、同来源的登录障碍只保留一个参与入口，停止原入口任务后转给仍自动等待的任务。核对账号不符时保留原账号，要求切回或修改委托。失败后出现的新入口有新的问题／请求身份；恢复登录后各任务重新观察，不解除原停止、接管、内容确认或未知结果。已有编辑现场不自动刷新；尚未编辑的页面经受控入口刷新后再观察，用户已编辑的页面需要先保存文字、刷新并明确继续。

独立记录进程在同一事务中取得、检查和释放目标占用，动作保存所属占用、运行和会话代次。不同稳定目标可并发，同一目标或身份不明的潜在冲突等待并说明。停止、待确认和未知结果保留仍有影响的占用；未派发预留取消或实际结果核对完成后才释放，不以超时抢走未知拥有者。前项已修改目标时，等待者重新读页；仍需改写才请求本任务的新取舍，旧内容确认不代替该回答。

记录格式 **15** 接续 14；迁移前保存原库，关系、占用和动作引用进入冷开与备份完整性检查，业务备份恢复仍先暂停。新增能力继续走原模型提议、预留、派发、结果和停止入口，没有站点专用动作脚本。15 的固定流程版本和单次确认边界保持。
