# 事项 23 P1 完整业务链路

2026-11-11，接续候选 107 和提交 `7c743a3`。本报告记录[固定五阶段计划](../../release-23-plan.md#p1打通完整业务链路)内的 P1 验收，首版 15 条整体验收另按原计划判定。

## 本机实包样本

| 样本 | 用户委托与独立核对 |
| --- | --- |
| F | 从文章列表首次探索，新建空白草稿，经附件库上传并关联，确认标题、富文本正文及栏目，核对公开页和原始 Excel |
| R | 新素材、标题、正文和栏目，选用 F 实际学得的版本，只由替代模型绑定本次输入 |
| C | 完整退出并冷开后新建任务，从记录恢复学得的流程，核对第三份输入的独立结果 |
| A | 固定 Excel 解析后由替代模型从实际单元格生成文章，两条数字事实、逐字段预览及原始附件独立核对 |
| D | 不同内容列表与类型选择、原生文件上传、文本域与必选栏目、发布表单直达结果页，使用同一产品入口 |
| I、U、N、S | 错配草稿来源、公开正文错配、已预览节点替换、附件送出后停止，各自核对后续效果和冷开状态 |
| F、P、R | 学得跨页流程后遇到编辑器结构和发布控件变化，核对修复结果及下一任务采用 |
| W | 接受发布约定和定时计划，由后台任务按时从固定 Excel 成文、跨页发布，核对未切换当前标签及已完成记录 |

F/R/C/A 的附件库路径对应现有 WordPress 环境记录中的选取、上传、插入和栏目确认。D 覆盖 Drupal 已观察到的列表新建、原生文件字段、栏目及 POST/303 结果。使用独立回环页面和虚构模型，不计入 P4 的真实后台十份样本。P4 仍需核对实际站点的编辑器、表单、登录与结果链接。

WordPress 实例记录的是区块编辑器的媒体库以及两次发布按钮操作。Drupal 实例记录的是从新增表单直接 Save 到内容页。本机样本的空白草稿创建、新编辑页自身及来源链接、公开页目标关联均来自夹具实际页面。P4 须核对真实站点能提供哪些对应证据。

## 运行安排

- 沿用现有固定开发签名与隔离资料入口，候选构建上限每次 10 分钟，先核对现有应用进程与共享租约。各轮单独串行运行。
- 业务、修复、定时各一轮，四个反例使用各自的隔离资料和网站端口，保留未知写入对站点的占用。单轮 5 分钟，启动或页面就绪 15 秒，业务阶段最多 40 秒。每轮最多 3 次启动、90 次本机替代模型请求。业务上限 5 次创建、5 次上传、4 次关联、5 次发布。修复各最多 3 次创建、上传、关联及发布。定时和每个反例至多各一次，按各自停止位置提前收束。夹具按样本拒绝重复效果。
- 相同失败至多初次加两次有依据的复跑，失败立即记录现场并由受管入口正常退出，核对自有 PID 和进程组。真实模型调用、远程业务写入、正式安装和系统权限变更均为 0。
