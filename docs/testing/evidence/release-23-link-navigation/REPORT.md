## 实现与停止边界

单步工作者启动前建立独立只读CDP订阅，最长16秒。记录原生门内所属鼠标释放的实际发送，以及同一页面首个`Page.frameRequestedNavigation`；只有`anchorClick/currentTab`、主frame和预先观察的href一致才产生进一步核对依据。该依据不由模型指定，原始导航事实仍保持`during-action`。

导航开始照常即时撤权并持久暂停。等旧工作者结束后，在最多6秒/20次只读检查中核对实际加载页的target、下一代次、精确URL、完整页面观察和同一网站会话。原生epoch须恰好包含宿主与控制侧原有两次撤权，额外输入、停止、其它导航或能力失效都使资格失效，不重新prepare吸收变化。可靠保存链接检查点并确认旧动作后，才授予新资格和排队剩余工作；保存期间的新停止或原生变化不能放行。

宿主`will-redirect`额外撤权，因此包括连续302后回到原href在内的重定向都保持暂停。没有新页面身份或已提交结果仍不明时不重发。只接受未绑定发布/准备目标、未进入流程重放的普通交互；链接到达不代表发布完成、业务目标身份已经建立，也不保证网站不存在隐含写入。

格式24接续23，升级前保存`workspace-before-link-navigation-23-*.sqlite`，旧记录不补造恢复证明。检查点结构校验覆盖来源链接、动作、代次、时间和原生epoch；冷开保留已确认事实，旧动作不可重新派发。本阶段没有新增真实备份导入组合，不将通用schema约束冒称完整备份验收。
