# 21：跨后台通用选择与私有管道顺序

2026-11-07。已实现有证据的通用修订；Drupal正式产品业务仍未验收，不解除15的真实前置。源码没有新增Drupal分支、网站选择器或预填流程。

## 实现

- 所属页面／frame的可访问观察保存实际选中标签，区分显示标签与内部值。选择确认必须匹配唯一控件，缺失、截断、歧义或标签变化保持未决并暂停；最终提交前再次核对，不用旧确认或页面文字替代。
- 原生单选框在实际选择前检查标签唯一性及可用状态；多选、自定义组合框、禁用或重复标签保持拒绝，仍经原私有控制与执行资格入口。
- 动作保存选择结果证明，冷开和备份验证标签、frame及确认状态。格式20接续19，升级前保留原库，不补造旧证明；流程仅从已核对动作形成，仍不携带另一任务的发布权限。
- 私有pipe按消息到达次序完成响应转接，再交付后续事件，修复同一数据块中事件越过Promise响应的问题。保留原缓冲区上限、session／frame／对象登记、停止及撤销。固定阶段错误码用于后续定位，不记录网页原文。
