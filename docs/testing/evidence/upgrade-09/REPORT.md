## 已实现

「关于与新版」提供准备升级、逐任务处理网页现场、原生目录选择及业务备份、可靠退出、取消准备和启动检查。准备期间统一阻止新的自动派发；原停止、人工接管和待确认保留，不能把升级暂停改成用户停止。任务、草稿、模型配置或网页现场变化使原退出资格失效，重复请求沿用已保存的操作身份及备份。
