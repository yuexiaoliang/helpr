修正提交 `ef08e36` 改用 `{width-36,28}`，位于既定布局中始终存在的右侧退出按钮内。原生匹配仍核对当前窗口、完整矩形、可见性及标签冲突，输入事件仍沿真实接收视图祖先确定归属；没有按点击坐标猜测任务、忽略未知或取消资格检查。固定失败分类保留，临时调试标记已清除。
