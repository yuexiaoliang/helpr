# 01 工作区实现核对

日期：2026-10-15。依据：[事项 01](../../../../.scratch/helpr-first-release-implementation/issues/01-installable-task-workspace.md)、`b4ea509` 中已确认的交互与视觉、已提交工程方案。实现已恢复，尚未通过完整产品验收；事项验收框保持未勾选，02 仍以前置 01 完成为条件。

## 已实现与工程检查

正式 TypeScript／Zod、React／CSS Modules／React Aria、XState、独立记录进程、better-sqlite3／Drizzle、Electron 多入口与独立 preload、Pino 本机诊断已贯通。支持创建两项真实任务、手动网站地址、独立对话和草稿、标签和悬停卡片、收起返回、明确退出和记录冷重开。仅开放受控只读观察，没有模型请求、自主网页动作、原生接管、计划或更新能力。

固定 Node 24.18.0、pnpm 11.7.0、Electron 44.7.2、builder 26.15.3 和精确产品锁文件。内嵌 Node 24.21.0、Chromium 152.0.7977.149。干净目录冻结安装通过，独立 `better-sqlite3` 实际加载 SQLite 3.53.4；不使用依赖展开模式。生成的初始迁移保存在源码，实际包带入迁移、独立 native 模块、进程映像检查器和原生退出监督。

当前 `pnpm check` 通过：5 个正式测试文件、12 项行为检查，严格类型、lint、格式与 187 个源码语法检查通过；旧浏览器回归 7 项来自此前独立结果，本次未重复。历史模型证据只是读取已有归档，本轮新增模型请求为 0。CI 入口已同步，尚未宣称远端 CI 运行通过。

关键测试从失败开始：任务记录、界面订阅、退出保存资格、实际提交但回执丢失、启动角色与验证资料。记录检查使用真实 SQLite、另一受管进程及实际目录不可写；不只检查内存回调。React 检查覆盖独立草稿与中文 composition Enter，不充抵真人输入法证据。源码审查修正记录及 UI 问题，见[两轴审查](review.md)。
