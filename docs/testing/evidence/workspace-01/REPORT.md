## 已实现与工程检查

正式 TypeScript／Zod、React／CSS Modules／React Aria、XState、独立记录进程、better-sqlite3／Drizzle、Electron 多入口与独立 preload、Pino 本机诊断已贯通。支持创建两项真实任务、手动网站地址、独立对话和草稿、标签和悬停卡片、收起返回、明确退出和记录冷重开。仅开放受控只读观察，没有模型请求、自主网页动作、原生接管、计划或更新能力。

固定 Node 24.18.0、pnpm 11.7.0、Electron 44.7.2、builder 26.15.3 和精确产品锁文件。内嵌 Node 24.21.0、Chromium 152.0.7977.149。干净目录冻结安装通过，独立 `better-sqlite3` 实际加载 SQLite 3.53.4；不使用依赖展开模式。生成的初始迁移保存在源码，实际包带入迁移、独立 native 模块和进程映像检查器。

最终 `pnpm check` 通过：5 个正式测试文件、8 项行为检查，严格类型、lint、格式与 182 个源码语法检查通过；旧浏览器回归 7 项通过。历史模型证据只是读取已有归档，本轮新增模型请求为 0。CI 入口已同步，尚未宣称远端 CI 运行通过。

关键测试从失败开始：任务记录、界面订阅、退出保存资格、实际提交但回执丢失、启动角色与验证资料。记录检查使用真实 SQLite、另一受管进程及实际目录不可写；不只检查内存回调。React 检查覆盖独立草稿与中文 composition Enter，不充抵真人输入法证据。源码审查修正记录及 UI 问题，见[两轴审查](review.md)。

## 尚待核对

失败时系统处于受保护输入；最新系统进程读取已不再列出先前的 SecurityAgent，但 helpr 窗口读取仍超时。已请用户核对弹窗：只有“helpr”访问自身 `helpr Safe Storage` 时才在该系统弹窗完成授权；若名称不同，先确认名称。弹窗内容尚未得到用户回报，未凭进程名称推定项目名称。没有让用户提供密码，没有修改钥匙串信任。未收到授权回报且窗口仍不可读取时，保留失败及应用现场，避免替换正在访问凭据的程序。

授权完成后，在既定额度内结束本轮自有进程、替换 build 5，按同一产品入口复验正向双页、实际首次绘制、独立对话和窄窗口键盘焦点、手动虚构登录、冷重开及意外退出。当前累计构建 5、安装 1、启动 6、故障 0、清理 1；上限分别 5、2、9、1、2。模型请求与远程业务写入均为 0。剩余额度失败就保存证据并停止，不把关闭错误弹窗或手动清理算作自动退出通过。
