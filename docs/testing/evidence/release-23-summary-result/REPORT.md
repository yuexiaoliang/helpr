## 产品行为及边界

管理页只显示标题等完整确认字段时，可从唯一、精确匹配的同站链接保存`confirmed-content-candidate-v1`结果候选；不再要求管理页同时展示正文、栏目、原编辑目标和附件。完整页面沿用旧`confirmed-content-link-v1`规则。候选可靠保存后只读核对对应公开页的唯一canonical、全部确认字段、栏目、原编辑目标唯一反向链接、附件及本机素材字节。

链接歧义、通用“查看”而无确认内容关联、跨站、片段、截断观察、错误公开页或字节不符均保持未知，不枚举链接、重发或取得新输入资格。两次稳定观察及页面／原生／会话／停止／保存边界保持。格式36接续35，迁移先保留旧库；冷开与备份保留结果检查点，导入仍待核对。不据此宣称所有管理页、私有下载或真实后台已经可用。
