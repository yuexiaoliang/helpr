## 已实现行为

本次发布预览绑定栏目、完整文字、当前目标版本的固定素材、稳定编辑目标与附件位置。用户修改文字产生新确认；旧确认、另一任务、不同素材或目标不可借用。附件发布最终点击前，系统通过单独 GET 比对上传附件的长度和 SHA-256，再取新的页面观察核对目标、全文、栏目与附件链接。动作继续经过同一个可靠预留、一次派发及临近发送的停止／原生输入检查。

最终点击的返回和页面后条件不足以完成素材任务。模型只能提议已观察的结果位置，系统单独读取同站公开页和附件，核对公开内容、栏目、唯一附件链接与固定字节。通过后在同一数据库事务保存已核实结果、素材处理完成、本次进度、动作后条件与流程候选。关键证据缺失保持未知，不重新上传或发布；观察到额外结果和异常会保存并停止后续动作。结果记录明确说明只覆盖公开页与附件，其它网站写入仍未知。截图不是完成的必要条件，本路径不调用截图，也不会为补截图重做业务。

流程候选由本次已确认动作生成，不接收模型脚本或预置网站步骤。候选含版本、父版本、摘要、适用范围、显式参数与来源、实际步骤前后条件、结果规则、恢复地址和验证来源；候选与采用引用同事务保存。**只验证过本次原输入，`newInputs=requires-validation`、`authority=none`**。新输入重放、执行固定流程版本及并发采用仍在 15／17 继续，不能将保存成功等同于这些能力已经成立。缺少步骤前条件的旧执行保留已核实业务结果，但不制造流程证据。

记录格式 12 接续 11，升级前保留独立数据库副本。业务备份包含新增结果、素材处理、完整候选和采用引用；备份读取与冷开核对候选摘要、动作、结果、素材与采用关联。仍沿用 8 MiB 单份素材、64 MiB 备份上限。恢复资料先暂停核对，不因备份里有历史成功就重新派发或把草稿记成完成。

公开结果检查当前限于同站、无需登录或重定向且能直接取得的 HTML 和附件；动态渲染公开内容、私有附件保持未知。HTML 解析不执行脚本，排除脚本／注释／隐藏属性／表单值；这不是完整 CSS 可见性、网站所有副作用或任意后台语义的证明。具体入口与边界见[验证安排](../../publication-13-plan.md)。

## 原始失败与修正

| 范围 | 现象与处理 |
| --- | --- |
| 首轮定向源码回归 | 备份版本断言仍为 11，已更新为 12；新派发校验误用于无附件的纯文字发布，已限定于素材任务，原参与确认回归通过。 |
| 新增测试装置初稿 | 把 `runId` 误传给无该字段的命令、冷开损坏测试使用错误表名；已修正装置，未作为产品故障。 |
| 首次完整源码检查 | 3 个模型用例返回 `MODEL_FORMAT`。新 URL schema 使用 `transform`，使实际 `z.toJSONSchema(nextStepSchema)` 在发送前抛错。改为可序列化的 URL 校验后原用例通过，最终完整检查全绿。构建 55 仅留档、不启动。 |
| [启动 157](RUNTIME-157.json)／候选 56 | 1 次本机模型返回选材提议时，前后页面观察不同，被原有资格检查拒绝。0 动作、0 上传／草稿／发布；正常退出，13 PID／3 组清空。[原记录](RECORDS-157.json)显示 `page_changed=1`，[OS 检查](AFTER-PROCESSES-157.json)独立确认清空。 |
| 157 后的验证器调整 | `manual` 只表示主页面状态，未证明子文档观察稳定。下一轮增加主／子 frame 及连续两次 DOM 快照稳定的只读准备检查，产品失效规则保持；158／159 全路径通过。157 未保存第二份完整观察，尚不能唯一判定是 iframe 加载、可访问性树形成还是导航时序，不把后续成功写成唯一根因已修复。 |
| 收尾发现的异常优先级缺陷 | 模型同时提议 `observe` 和异常时，循环先继续观察而跳过异常保存。[最小源码反例](ANOMALY-RED.txt)失败；将异常保存移到 `observe` 之前后，同一测试通过。后续核对还会读取已保存异常，模型省略异常字段或重送旧成功证明均不能完成任务；该新增反例及最终完整 175 项应用检查通过。此修正进入后续最终候选，不改写 56 的原始证据。 |

事项 12 的 149／154 iframe 点击超时与本次 157 的**派发前旧观察拒绝**不同；原点击超时的唯一根因仍未确认，本轮没有把它标记修复。没有删除原失败或通过重送消除未知。
