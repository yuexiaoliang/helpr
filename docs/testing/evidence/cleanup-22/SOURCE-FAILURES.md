# 22：原失败及限制

2026-11-07，以下均为当前源码／隔离测试，不是远程业务调用。

1. 初稿类型检查发现控制投影发布函数无参数，随后修正为先采用不旧于当前版本的投影再发布；诊断关闭初稿引用了ThreadStream未声明的`destroyed`字段，改为监听真实`close`事件。
2. 删除失败测试最初spy默认导出的`fs.unlinkSync`，未拦截模块中的命名导入，得到`complete`而非预期`pending`。这是注入装置失败，不能算删除故障已覆盖。改为仅对本轮临时`materials`目录设只读权限，实际删除返回拒绝；恢复权限后原请求重试通过，原文件和处理事实保留。
3. 扩展定向检查初轮66/68通过；旧备份测试仍期待格式20，原保存失败测试仍期待权限恢复后直接重试。新格式21和故障后显式保存检查使这两条失败。按新约定调整期望及公开检查动作，原输出见[SOURCE-TARGETED-INITIAL](SOURCE-TARGETED-INITIAL.txt)。
4. 新共享文件及UI夹具尝试使用一般`finish`把带素材任务记为完成，被既有`PUBLICATION_RESULT_REQUIRED`拒绝，共3条准备失败（7/10通过）。未放宽产品守卫，改用现有正式发布入口取得实际本机HTTP字节及结果；共享案例采用独立首次学习，不通过改写数据库伪造完成。原输出见[SOURCE-FIXTURE-FAILURES](SOURCE-FIXTURE-FAILURES.txt)。修后10条通过。
5. 首轮整套检查在lint发现两个测试async函数无await，未进入整套测试。修正后重跑，原输出见[SOURCE-LINT-INITIAL](SOURCE-LINT-INITIAL.txt)。
6. 审阅补充清理历史在控制入口直接拒绝“继续”与新约定／计划，避免记录拒绝后留下未保存临时阻断；专项同时核对拒绝后仍可正常退出。
7. CUA首次`getState`在10秒超时并重置，无页面或原生窗口证据。本轮未请求新标签；21所请求IAB标签清理仍未知，没有终止共享浏览器宿主。
