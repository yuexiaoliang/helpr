# 18：读取 Excel、预览与确认文章

2026-11-07，已完成独立实现、自动验收与固定包验证。本项 **6/9 条关闭**；真实内容模型／WordPress 及原生预览编辑仍待集中验收，`Blocked by: 13` 保持。方案与边界见[检查安排](../../article-18-plan.md)，成熟库比较与一手来源见[解析选型](../../../research/excel-content-parsing.md)。没有自研通用解析器、写入验收文件或栏目专用产品逻辑，也没有为历史原型阶段表述等待审批。

## 实现

- 只读取已固定、摘要核对过的素材副本。锁定 SheetJS CE 0.20.3 官方 tarball，yauzl 3.4.0 与 saxes 6.0.0 做有界 ZIP／公式元数据核对。解析在有时限与堆限制的工作线程运行；记录拥有者仍可保存停止。
- 原类型、原值、显示格式、表／格位置、公式及不确定状态保留。1900／1904 日期系统分开，序号 60 不当公历事实；空白、空字符串、零、false 不互换。共享公式标签缺失仍按原 XML 标记拒绝作为事实。所有公式缓存均不作为确定值，不重算，也不将缺失缓存补成零。隐藏和合并从属格不可引用；外部连接与不支持格式明确反馈，超限整份拒绝。
- 本次目标与补充回答形成处理要求版本。生成请求绑定任务、来源摘要及要求版本，调用用途为 `material-content`；请求摘要、模型配置版本、原输出与文章关联。段落引用逐项核对真实位置及原值，数字不能由模型自行计算后冒充源表值；没有素材依据的意见明确标为建议。引用匹配不能证明所有自然语言语义正确。
- 所属任务预览完整文字、实际附件与目标，可展开原表位置及不确定项。修改全文产生父子版本；新增／改写文字标为用户编辑，未自动获得表格来源。修改目标或要求走新目标版本与撤权入口。单次确认仍由唯一记录进程原子接受，绑定文章、素材、目标和任务；旧回复、另一任务回复或“继续”不授予新版权限。
- 发布仍核对当前预览、网页全文／栏目、附件字节及实际公开结果；来源文件后来改变不替换固定素材，失败不将素材标为完成。格式 17 接续 16，迁移先留原库；解析、要求、文章／父版、调用来源、确认和提交引用进入冷开及备份校验。模型原始 JSON 留作记录，普通对话只显示处理说明。
