## 已完成的源码

- 控制拥有者分别接入锁屏、休眠、会话条件；启动期间先收集事件，执行入口建立后交付。唤醒取样不解除已收到的锁屏。
- 收到系统阻断先同步撤销输入资格、旧网页工作者与模型请求，再由独立记录进程保存原活动任务的恢复检查点。锁屏与休眠全部解除且检查点保存成功后先核对，不能直接重发。
- 原停止、人工接管、输入未知、原待参与／结果不明保持。新的系统事件、停止或输入撤销旧核对；领取已提交但回执迟到、继续准备跨锁屏均有公开入口回归。
- 任务状态与地址栏显示系统暂停和休眠期间不保证按时执行。关闭主窗口／菜单栏返回沿用既有真实窗口和网页；本轮尚未取得这一组合的实际 UI 证据。
- 恢复检查点沿用资料格式 5，没有迁移或替换正式用户资料。原型保持独立分支。
