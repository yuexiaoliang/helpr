## 已确认的入口

3. **应用运行、版本检查与资料恢复**：通过真实启动／退出和独立 OS 进程树检查唯一拥有者、旧控制隔离、正常及异常清理。原生运行组件可先用独立 Node 进程形成紧反馈，不冒充实际安装包通过。

## 切片

- 原活动任务冷重开进入待核对；停止、接管、输入未知及待参与暂停保留；旧 run／预留不再放行。
- 网站效果与本机记账之间中断后自动只读核实，无重复效果；未知不重发，可信未派发检查点只允许新的剩余动作。
- 旧核对、提交回执丢失、记录进程失联、恢复中新停止或目标改变，不能覆盖新资格。
- 正常退出先封住新派发、等待必要事实保存，再收束进程；异常退出由独立原生监督结束自有运行组。新启动取得资料区独占运行租约后才读记录与恢复。
- 数据与状态版本、缺失／损坏资料保留并拒绝不安全恢复；不能重建的网页说明原因，不自动创建可执行空白任务。

原生监督与锁的检查使用新建的独立测试目录和自有进程。实际包核对在源码及两轴审阅后固定候选、案例和有限批次；保留原全局 29 构建／8 安装／69 启动尝试／34 故障／15 清理，不占用或重置已结束的 04 夹具额度。当前源码检查不安装应用、不读取真实凭据、不调用真实模型或远程业务。
