# 01 工作区实现与核对

实现依据：[事项 01](../../.scratch/helpr-first-release-implementation/issues/01-installable-task-workspace.md)、已确认的 `foundation-v2` 交互与 `foundation-v3` 第 4 款无竖线标签栏（`b4ea509`）。

沿用规格中已经确认的三组公开入口，本项只覆盖：

- 意图与记录：创建任务、发送所属任务消息、保存输入、读取工作区；真实 SQLite、另一进程重开和保存失败，不评估模型理解。
- 网页工作区：打开所属真实页面、手动导航和登录、读取所属页面；独立接收端核对页面归属，拒绝跨任务、外部和写入控制，不评估自主执行。
- 应用运行：独立安装包启动、退出、重开；核对实际进程、原任务、对话和有效会话，不能仅凭退出通知认定进程退出。

先用一个失败用例贯通任务记录，再接入网页与安装包；实现技能要求的测试与规格审查随后完成。

本轮自动验收上限：最多 3 次构建、1 次安装、6 次应用启动、1 次意外退出注入、1 次必要残留清理。每次准备和失败都累计；运行不超过 30 分钟。模型调用 0，远程业务写入 0。登录测试仅使用本机 HTTP 夹具和虚构会话，不读取原实验的登录资料或密钥。超出上限先保存结果及具体追加方案。实际运行计数保存在 `.local/workspace-validation/budget.json`，脱敏结论另存证据目录。

正常开发检查不启动应用、模型或远程网页，不消耗上面的实包次数。生产资料固定在用户应用资料目录，验证资料独立；构建包、浏览器资料和数据库均遵循 ignore。
