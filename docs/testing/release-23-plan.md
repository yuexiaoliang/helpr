## 本轮可独立完成的工作

1. 对构建输入记录逐文件SHA-256、源码提交与未提交状态、真实Node／pnpm版本、依赖锁、资料格式和状态模型。构建前后核对输入一致，同名候选不得覆盖。
2. 生成生产依赖声明和上游已有许可证／NOTICE正文，随实际包保存Electron／Chromium及图标材料；缺少根许可证正文明确列出，不用SPDX名称替代正文或宣称法律审查完成。
3. 对签名后的整个应用记录文件、权限与内部符号链接。独立预检核对完整包、两层宿主、原生组件、迁移、实际ASAR依赖及随包元数据。源码树、包或迁移变化都使原预检失效。
4. 新空目录离线冻结安装，依照原allowBuilds执行依赖构建；保留完整输出和锁文件不变依据。该安装不启动Electron，不算用户正式安装，也不声称从这个空目录已经构建和运行完整应用。
5. 同一候选只运行本机清理／发布回归，作为新打包资源的冒烟核对。脚本虚构模型、线性网页不充抵五项真实业务。

本轮上限：1次初始构建，1轮受管应用回归（最多3次启动、3份附件上传、3次草稿、3次本机发布），应用总时限5分钟、阶段50秒；构建／审计分别限10／2分钟，干净安装120秒。只有具体修正或新依据才复跑并累计。所有真实模型、远程业务写入、正式安装、系统权限变更均为0。进程和共享租约检查在启动前完成；退出后独立核对自有PID与组。CUA只读清单失败时保留待验，不能从产品进程清空推定旧IAB标签已关闭。
