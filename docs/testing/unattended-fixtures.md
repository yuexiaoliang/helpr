## 边界

入口需同时显式选择 `--workspace-validation --workspace-fixture`，继承父进程通道，使用固定 OS 临时根下的独立资料目录，并指定 `HELPR_FIXTURE_ORIGIN=http://127.0.0.1:<port>`。普通启动不能选择此模式；独立网页宿主还需验证同包控制者和原生监督进程，正式资料目录拒绝虚构模式。仅设置环境变量不会改变普通启动。

控制者在此模式只接受公开哨兵 `local-fixture-not-a-secret`，本次进程产生的虚构凭据引用不能解开真实密文或另一进程的引用。模型端点限定为该回环来源的 `/v1`。此适配不调用系统加解密，不接受真实 API key；不验证真实凭据加密、密钥恢复或跨重启凭据延续。

网页使用无 `persist:` 前缀的临时会话；网页 HTTP 请求只放行指定回环来源及初始化空白页，外部页面／重定向拒绝。正常启动仍使用原来的系统凭据保护、持久网页会话和权限策略，签名及 macOS 安全设置不变。接管、执行、可靠记录及资格门仍走实际产品路径。

`validate-takeover.mjs` 在保存配置前检查宿主回报的虚构模式、来源和非持久会话。配置保存限定十秒；此处不存在应交给人处理的授权步骤，意外阻塞记为失败并正常收束，不再要求用户守在电脑旁。其它专门验证真实系统凭据的入口保留其人工交接安排，不把本模式的成功计入真人授权验收。
