## 源码范围

控制拥有者分别持有锁屏和休眠条件，收到阻断事件先同步撤销输入与派发资格，再可靠保存活动执行的恢复检查点。系统条件恢复不写入用户“继续”，只让原活动任务核对；停止、人工接管、待参与及结果不明按原有条件保留。旧模型、网页、保存或核对返回不得解除新暂停。记录进程仍独占可靠事实；界面订阅运行条件，不以展示状态授予执行许可。

关闭窗口／菜单栏返回沿用现有真实窗口与页面，补齐运行条件提示。不会改变 Mac 休眠设置。首版定时计划仍属事项 20。

两个启动沿用同一个候选：第一轮由 agent 用实际 UI 核对双任务、收起／菜单栏返回、真实页面文字及观察记录，再正常退出；第二轮承接第一轮用量，在准备就绪后做真人输入与系统生命周期。两轮合计最多 4 个虚构任务、24 次本机受控模型、8 次本机页面推进及 16 条网页输入收件，各轮活动阶段最多 20 分钟；准备与独立退出另各不超过 60 秒／45 秒。真人确认与工具输入分别记录。持续运行测量纳入同一批次，不以网页／模型等待代替响应性能，不预先宣称性能门槛已定。

入口：`node scripts/validate-takeover.mjs --round=lifecycle-06-auto --build=33 --lifecycle`；第二轮同候选使用 `--round=lifecycle-06-human --carry=lifecycle-06-auto`。`--lifecycle` 将夹具限额固定为上述数值，并仅允许同属 06、前轮已正常退出或已独立清理的记录承接，不能带入其它事项清零。实际包由该入口独占启动、标签与子进程；既有原型预览保持空闲，不同时自动驱动浏览器。进程 PID／PPID／PGID 与确认自有组由 OS 保存，正常退出后独立复查；失败先停，必要时只清理本轮所属 PID／组，确认无残留前不再启动。

系统事件采用冻结 Electron `44.7.2` 的本地类型与 [powerMonitor 官方文档](https://www.electronjs.org/docs/latest/api/power-monitor)核对 API；事件接入不代表 Mac 真实组合已通过。唤醒的屏幕取样不会解除已收到的锁屏，明确解锁事件才能解除该条件。
